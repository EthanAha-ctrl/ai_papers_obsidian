# 深度解析：为什么 1/0 = 0 在数学上可以成立

## 文章核心论点

这篇文章由 Hillel Wayne 于 2018 年撰写，源于一场关于编程语言 Pony 的 Twitter 争论。作者的核心论点是：**定义 1/0 = 0 在数学上是完全自洽的，并且被多个主流定理证明器采用**。

---

## 数学基础：域与除法的形式化

### 域的公理化定义

文章首先建立了严谨的数学框架——**域**。一个域由集合 S 和两个运算 (+, ×) 组成，满足以下公理：

| 公理类别 | 具体内容 |
|---------|---------|
| 封闭性 | ∀a, b ∈ S: a + b ∈ S, a × b ∈ S |
| 交换律 | a + b = b + a, a × b = b × a |
| 结合律 | a + (b + c) = (a + b) + c, a × (b × c) = (a × b) × c |
| 分配律 | a × (b + c) = a × b + a × c |
| 加法单位元 | ∃0 ∈ S: a + 0 = a |
| 乘法单位元 | ∃1 ∈ S: a × 1 = a, 且 1 ≠ 0 |
| 加法逆元 | ∀a, ∃(-a): a + (-a) = 0 |
| 乘法逆元 | ∀a ≠ 0, ∃a⁻¹: a × a⁻¹ = 1 |

**关键洞察**：注意乘法逆元的存在性只对非零元素要求。这意味着域的公理体系中，**0 没有乘法逆元是公理的结论，而非假设**。

### 经典证明：a × 0 = 0

文章给出了一个优雅的形式化证明：

```
1. 0 + 0 = 0                          (加法单位元定义)
2. a × 0 = a × (0 + 0)                (代入)
3. a × (0 + 0) = a × 0 + a × 0        (分配律)
4. ∃-(a × 0): -(a × 0) + (a × 0) = 0   (加法逆元存在性)
5. a × 0 = a × 0 + a × 0              (由 2, 3)
6. -(a × 0) + (a × 0) = -(a × 0) + (a × 0 + a × 0)  (代入)
7. 0 = a × 0                          (由 4, 6, 加法逆元消去) ∎
```

由此立即推出：**0 没有乘法逆元**。因为假设 0⁻¹ 存在，则 0 × 0⁻¹ = 1，但已知 0 × 0⁻¹ = 0，故 1 = 0，与公理 1 ≠ 0 矛盾。

## 除法定义的扩展

### 传统定义的局限性

传统除法定义为：**a/b = a × b⁻¹**。但这带来问题：

- 当 b = 0 时，b⁻¹ 不存在
- 许多定理需要额外前提：**IF b ≠ 0, THEN a/b = a × b⁻¹**

例如：
- **定理**：IF a ≠ 0, THEN a/a = 1
- **定理**：IF c ≠ 0, THEN a × (b/c) = b × (a/c)

### 三种扩展策略

| 策略 | 做法 | 代表系统 |
|-----|------|---------|
| **禁写** | 不允许表达式 1/0 出现 | Agda, Idris |
| **扩展值域** | x/0 = ⊥ 或 ∞（扩展到超实数） | Riemann 球面 |
| **常值扩展** | x/0 = C（某个固定常数） | Isabelle, Lean, Coq |

作者重点讨论第三种策略，特别是 **C = 0** 的选择。

### 为什么选择 0？

关键优势：**可以强化某些定理，移除非零前提**。

**定理强化示例**：

```
定理：a × (b/c) = b × (a/c)

证明：
  若 c ≠ 0：已知成立
  若 c = 0：
    左边 = a × (b/0) = a × 0 = 0
    右边 = b × (a/0) = b × 0 = 0
    故左边 = 右边 ∎
```

但如果选择 C = 1：
```
左边 = a × 1 = a
右边 = b × 1 = b
一般不成立！
```

## 常见反证为何失败

### 反证 1：推导 1 = 0

```
1/0 = 1
1/0 × 0 = 1 × 0
1 × 0/0 = 0      ← 错误在此！
1 = 0
```

**错误分析**：步骤 3 使用了定理 a × (b/c) = b × (a/c)，但该定理需要 c ≠ 0 的前提。即使定义了 1/0，定理的前提条件不会自动消失。

### 反证 2：乘法逆元不唯一

```
2/2 = 1, 2/0 = 0
所以 2 有两个"逆元"？
```

**错误分析**：混淆了 **"除法结果"** 与 **"乘法逆元"**。
- 2⁻¹ = 1/2 是通过乘法定义：2 × (1/2) = 1
- 2/0 = 0 不是乘法逆元，因为 2 × 0 = 0 ≠ 1

**核心区别**：
$$\underbrace{\frac{a}{b}}_{\text{除法运算结果}} \neq \underbrace{a \times b^{-1}}_{\text{乘法逆元}} \quad \text{当 } b = 0$$

## 为什么定理证明器选择这个定义？

### 形式化验证的实际需求

Lawrence Paulson（Isabelle 的发明者）解释：

> "在 Martin-Löf 构造类型论中开发算术时，需要一个（必然是原始递归且可执行的）除法定义。它自然地给出 n/0 = 0。"

**技术原因**：

1. **全函数要求**：在依赖类型理论中，所有函数必须是 total function。若除法是偏函数（只在非零分母上有定义），需要额外处理（如 dependent types）

2. **可执行性**：定理证明器常需要计算/化简表达式。定义除法为全函数简化了实现：
   ```
   div :: Nat -> Nat -> Nat
   div a 0     = 0    -- 必须给出某个值
   div a (S b) = ...  -- 正常情况
   ```

3. **定理简化**：如上所示，许多定理可以免去"分母非零"的前提检查

### Leslie Lamport 的视角

Lamport（2013 年图灵奖得主）指出：

> "在 ZF 集合论中，由于 0 不在倒数函数的定义域内，我们对 1/0 的值一无所知；它可能等于 √2，可能等于 ℝ，可能等于任何东西。"

这反映了数学中的 **定义自由度**：只要不引入矛盾，我们可以自由选择扩展定义。

## 极限视角的反证及其问题

### 反证：利用极限

```
如果 0/0 = 0，那么：
lim(x→0) sin(x)/x = sin(0)/0 = 0

但由 L'Hôpital 法则：
lim(x→0) sin(x)/x = lim(x→0) cos(x)/1 = 1

矛盾：0 = 1
```

**问题所在**：该论证假设：
$$\text{若 } \lim_{x \to a} f(x) \text{ 存在且 } f(a) \text{ 有定义，则 } \lim_{x \to a} f(x) = f(a)$$

这是 **连续性** 的定义，而非极限的一般性质！

定义扩展后，sin(x)/x 在 x=0 处是**可去间断点**（removable discontinuity），极限值 ≠ 函数值是正常的。

## 数学上的延伸：Wheel Theory

这篇文章引发了一个有趣的数学延伸——**Wheel Theory（轮理论）**。

在 Wheel Theory 中：
- 引入新元素 ⊥（或写作 ⟂）表示 "undefined"
- 定义：0/0 = ⊥, x/0 = ∞·x（其中 ∞ = 1/0）

这创造了一个**除法始终有定义**的代数结构，但代价是：
$$\frac{x}{x} \neq 1 \quad \text{一般情况}$$
$$\frac{x}{x} = 1 \text{ 当且仅当 } x \neq 0, x \neq \bot$$

相关文献：
- [Wheels: On division by zero](https://www2.math.su.se/reports/2001/11/) - Jesper Carlström

## 编程语言 vs 定理证明器

作者强调关键区别：

| 方面 | 定理证明器 | 编程语言 |
|-----|-----------|---------|
| 目标 | 数学自洽性 | 安全性、实用性 |
| 除零处理 | 返回约定值 | 通常抛出异常 |
| 原因 | 需要全函数 | 需要错误暴露 |

**Pony 的设计理由**（据开发者反馈）：Pony 强制处理所有偏函数。定义 1/0 = 0 是"两害相权取其轻"的选择。**但 Pony 后来已支持偏除法**（partial division）。

## 我的直觉构建

### 核心洞察

1. **定义是自由的**：数学公理体系给了我们"空间"——只要不导致矛盾，我们可以任意扩展定义。

2. **直觉是局限的**：我们直觉认为 a × b 是 "b 个 a 相加"，但这无法解释 (-1) × π。同理，除法的"乘法逆元"直觉在 0 处失效。

3. **定理 > 直觉**：关键不是"感觉对不对"，而是"能否证明某个定理"。定义 x/0 = C 后，原来的定理（带条件）依然成立，只是某些定理可能更强。

4. **语境决定选择**：
   - 纯数学家：用传统定义，99%的数学不需要考虑 0 分母
   - 逻辑学家/证明器开发者：需要全函数，选择约定值
   - 程序员：需要错误暴露，选择异常

### 类比：0^0 = 1

类似的情况：定义 **0^0 = 1** 在组合数学和计算机代数系统中很常见，因为：

$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

当 n = k 时，需要 0! = 1，进而 0^0 = 1（通过空积的约定）。

参考：[What is 0^0?](https://scipython.com/blog/what-is-00/)

## 总结

这篇文章的价值在于：

1. **破除教条主义**："数学上不允许除以零"是教学简化，不是绝对真理
2. **展示严谨性**：通过形式化证明展示为什么定义是自洽的
3. **区分语境**：数学自洽 ≠ 编程最佳实践
4. **倡导谦逊**：正如作者所言——"Don't make fun of other people. The world is big and we are small."

**最终洞察**：数学不是教条的规则集合，而是**开放的建构游戏**。只要自洽，我们就可以创造新定义、新结构，而这正是数学的"playful and delightful"之处。
