
## 一、研究背景与动机

### 1.1 6G通信系统的挑战

**5G FR3频段和6G的要求：**
- 频率范围：5G FR3频段为 7.125–24.25 GHz
- 6G将推向更高频率
- 通道带宽需求：100–400 MHz（5G FR3），超过1 GHz（未来6G）

**RF前端模块的组成：**
```
Antenna → Band-pass Filter → LNA/PA → Mixer → LO → Digital Processing
```

### 1.2 现有技术的局限性

**传统SAW/BAW滤波器的限制：**
- SAW（Surface Acoustic Wave）：适用于<6 GHz
- BAW（Bulk Acoustic Wave）：高频扩展困难
- 商业RF前端需要超过100个固定频率滤波器
- 成本和尺寸随频段数量增加而急剧增长

**频率可重构滤波器的挑战：**
- 铁电材料（如BaSrTiO₃）：调节范围有限
- 相变材料：速度慢、功耗高
- 可变电容（Varactors）：线性度有限

### 1.3 自旋波技术的优势

| 特性 | 自旋波 | 声波 | 电磁波 |
|------|--------|------|--------|
| 波长 | 中等 | 极短 | 长 |
| 可调性 | 天然（磁场） | 有限 | 固定 |
| 高频性能 | 提升 | 下降 | - |
| 尺寸独立性 | ✓ | ✗ | ✗ |

**自旋波的核心优势：**
1. **天然可调性**：通过外部磁场H<sub>DC</sub>调节频率
2. **高频性能提升**：Q因子和耦合系数随频率增加而改善
3. **尺寸独立于频率**：不同于声波器件

## 二、自旋波的物理原理

### 2.1 自旋波的基本概念

**定义：**
自旋波是铁磁或亚铁磁材料中磁化强度进动的传播扰动，存在于如YIG（钇铁石榴石）材料中。

**YIG的关键参数：**
- 饱和磁化强度：M<sub>s</sub> = 178 mT
- Gilbert阻尼因子：α ≈ 10⁻⁴
- 低非均匀展宽

### 2.2 自旋波的色散关系

**有效磁场公式：**
```
H_eff = H_DC - N_z · M_s
```

其中：
- H<sub>DC</sub> = 外部施加的直流偏置磁场
- N<sub>z</sub> = 垂直方向的去磁化因子（与几何形状相关）
- M<sub>s</sub> = 饱和磁化强度

**去磁化因子N<sub>z</sub>的影响：**
对于矩形棱柱，N<sub>z</sub>由几何形状决定。窄的YIG鳍片具有较小的N<sub>z</sub>，导致：

1. 较小的去磁化场
2. 较大的自旋波波矢量k<sub>mn</sub>
3. **更高的共振频率**（在相同外部偏置下）

### 2.3 串联-并联谐振频率分离

**频率分离机制：**
```
Δf = f_shunt - f_series ≈ 1.24 GHz
```

通过设计对比：
- **串联谐振器**：宽YIG mesa（50 μm宽）
- **并联谐振器**：窄YIG鳍片阵列（12 μm宽）

这种几何对比产生足够的k<sub>mn</sub>和N<sub>z</sub>差异，实现单磁场下的频率分离。

## 三、滤波器架构与设计

### 3.1 梯形滤波器原理

**基本结构：**
```
Input ──[Series R]──[Shunt R]──[Shunt R]──[Series R]── Output
               │              │              │
              GND            GND            GND
```

**类比压电MEMS声学滤波器：**
- 传输机制不同：SW使用横向RF磁场，压电使用电场
- 电路模型相同：LC谐振网络

### 3.2 分布式自旋波谐振器模型

**等效电路模型：**

```
        Z0 (传输线)
    ┌─────────────┐
    │     R0      │
    └─────────────┘
         │
    ┌────┴────┐
    │         │
  [Cm]      [Rm]
    │         │
  [Lm]       │
    │         │
    └────┬────┘
         │
        GND
```

**关键参数：**
- R<sub>0</sub>：串联电阻（金传输线电阻）
- Z<sub>0</sub>：传输线特性阻抗，P<sub>0</sub>为物理长度
- R<sub>m</sub>, C<sub>m</sub>, L<sub>m</sub>：并联谐振网络参数

**频率响应特性：**
- **共振频率（f<sub>p</sub>）**：高阻抗（并联谐振）
- **反共振频率（f<sub>s</sub>）**：低阻抗（串联谐振）

### 3.3 带通滤波器设计要求

**频率对齐条件：**
```
f_shunt,p ≈ f_series,s
```

即并联谐振器的共振频率与串联谐振器的反共振频率对齐。

**远离共振时的行为：**
滤波器表现为电感分压器网络，带外抑制由以下决定：
1. 谐振器级数（阶数）
2. 串联-并联传输线阻抗对比

### 3.4 实际器件设计参数

**串联谐振器规格：**
```
尺寸：1000 μm × 50 μm × 3 μm
金传输线：3 μm厚
底部接地平面：距YIG 10 μm
传输线宽度：60% YIG宽度
```

**并联谐振器规格：**
```
结构：6个平行YIG鳍片阵列
单个鳍片：600 μm × 12 μm × 3 μm
金传输线：3 μm厚
底部接地平面：距YIG 10 μm
传输线宽度：60% YIG宽度
```

**设计权衡：**
| 参数 | 增大 | 减小 |
|------|------|------|
| 传输线宽度 | 低阻抗（抑制好） | 高k<sub>eff</sub>²（带宽大） |
| GGG薄膜厚度 | 高Q（低损耗） | 高k<sub>eff</sub>² |
| 谐振器长度 | 高k<sub>eff</sub>² | 高频扩展 |

## 四、制造工艺流程

### 4.1 关键工艺步骤

**阶段1：正面加工（图3a-j）**

```
a. Ti/Au硬掩模沉积
   └─ 300 nm Ti / 100 nm Au / 电镀 Au

b. 光刻图案化

c. YIG离子刻蚀（深度3 μm）

d. Ti粘附层沉积（15 nm）

e. 金电镀（3 μm）

f. PR剥离

g. 缓冲氧化物刻蚀剂湿刻Ti

h. Au湿刻

i. Ti硬掩模湿刻（150 nm厚）

j. SEM检查
```

**关键工艺控制：**
- Ti硬掩模厚度（150 nm）防止Au刻蚀期间完全底切
- 窄并联传输线不被完全底切

**阶段2：背面加工（图3k-r）**

```
k. 保护层沉积：Ti/Au/电镀Au（300/100/785 nm）
   └─ 保护YIG谐振器抵抗热磷酸刻蚀

l. 蜡键合到Si载体
   └─ 机械抛薄至101 μm
   └─ 厚度均匀性：±1 μm

m. 背面电镀Au硬掩模（lift-off工艺）

n. Au硬掩模微检查

o. 160°C磷酸刻蚀GGG衬底
   └─ 留下10 μm薄膜

p. Au和Ti硬掩模去除（湿刻）

q. 背面蒸发掠射角Au层（接地平面）

r. 最终检查
```

### 4.2 工艺创新点

1. **深各向异性GGG刻蚀**：形成10 μm薄GGG薄膜
2. **背面接地平面**：实现高耦合系数k<sub>eff</sub>² ≈ 18%
3. **无需通孔**：简化工艺，提高良率

## 六、频率可调无线电演示

### 6.1 实验设置

**系统框图：**
```
PRBS(20 Mbps) → IQ调制器 → f0 → 20 dB衰减器(AWGN) →
                              ↓
                           干扰源 → ──→ YIG可调滤波器 → IQ解调器 → I/Q输出
                              ↑
                           频率扫描控制器 + 电磁铁
```

**关键参数：**
- 调制：QAM（正交幅度调制）
- 数据率：20 Mbps
- 通道：AWGN（加性白高斯噪声）
- 频率调节：18 → 8 GHz，0.5 MHz步进

### 6.2 无干扰情况下的性能

**频率点：**
- f<sub>0</sub> = 12 GHz
- f<sub>0</sub> = 17 GHz

**结果：**
- 清晰的眼图
- 明显的I/Q星座点
- 证明滤波器在整个调节范围内维持信号完整性

### 6.3 干扰抑制演示

**干扰设置：**
```
信号频率：f0 = 17 GHz
干扰频率：fi = 17.3 GHz（距信号300 MHz）
干扰类型：AM调制高斯噪声
```

**输入功率谱：**
```
17.0 GHz: -57 dBm（信号）
17.3 GHz: -42 dBm（干扰，高15 dB）
```

**结果：**
- YIG滤波器充分衰减干扰
- 维持足够的SNIR（信噪干扰比）
- 保持可解调的I/Q星座

### 6.4 调节速度

**当前限制：**
- 电磁铁电感限制
- 不是SW滤波器本身

**潜力：**
- 快速调节磁偏置可实现快速跳频
- 适用于认知无线电和抗干扰系统

## 九、详细技术公式解析

### 9.1 自旋波共振频率

**磁静态前向体波（MSFVW）色散关系：**

```
f = γμ0√[H_eff(H_eff + M_s)]
```

其中：
- γ = 旋磁比（≈ 2.8 MHz/Oe for YIG）
- μ<sub>0</sub> = 真空磁导率 = 4π×10⁻⁷ H/m
- H<sub>eff</sub> = H<sub>DC</sub> - N<sub>z</sub>M<sub>s</sub>

**几何去磁化因子N<sub>z</sub>：**

对于矩形棱柱，N<sub>z</sub>由Aharoni公式近似：
```
N_z ≈ f(t_YIG, w_YIG, l_YIG)
```

较窄的YIG鳍片具有较小的N<sub>z</sub>，导致：
- H<sub>eff</sub>增大
- f共振增大

### 9.2 耦合系数k<sub>eff</sub>²

**定义：**
```
k_eff² = (f_p² - f_s²) / f_p²
```

**影响因素：**
1. 横向RF磁场约束（主要因素）
2. 底部接地平面距离（t<sub>GGG</sub>）
3. YIG厚度
4. 传输线设计

**本文设计实现：**
```
k_eff² ≈ 18%（传统<3%）
```

实现方法：
- 背面GGG刻蚀形成10 μm薄膜
- 接地平面贴近YIG
- 通过GGG通孔包裹换能器（hairclip设计）

### 9.3 品质因子Q

**并联谐振品质因子Q<sub>p</sub>：**
```
Q_p = f_p / Δf_3dB,p
```

**影响因素：**
1. YIG材料特性：
   - 低非均匀展宽
   - 低Gilbert阻尼α ≈ 10⁻⁴

2. 实验测得Q<sub>p</sub>：
   - Q = 1,313 @ f<sub>p</sub> = 11.6 GHz
   - Q = 2,206 @ f<sub>p</sub> = 6.79 GHz

**串联反共振品质因子Q<sub>s</sub>：**
```
Q_s ≈ (ωL_m / R_0) × (Z_0 / R_m)
```

主要受传输线设计影响：
- 低电阻率Au换能器
- 宽传输线（60% YIG宽度）

### 9.4 滤波器设计方程

**带宽方程：**
```
BW_3dB ≈ k_eff × f_center
```

**阻抗匹配条件：**
```
Z_0,series × Z_0,shunt = Z_source × Z_load
```

对于50 Ω系统：
```
Z_0,series ≈ √(50 × Z_shunt_off_resonance)
```

### 9.5 线性度指标

**三阶互调截点（IIP3）：**
```
IIP3 = P_in - (ΔP_IM3 / 2)
```

其中：
- P<sub>in</sub> = 基频输入功率
- ΔP<sub>IM3</sub> = 三阶互调产物相对基频的功率差

**本文结果：**
```
IIP3 ≥ 11 dBm @ 716.3 mT
```

这意味着：
- 输入功率达到11 dBm时，三阶互调产物与基频功率相等
- 通常设计工作点低于IIP3 10-15 dB

## 十、总结与展望

### 10.1 核心贡献

1. **单磁场梯形滤波器架构**
