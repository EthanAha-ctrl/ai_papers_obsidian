# 用人话讲 V0.5

好，咱们把数学都放一边，就当喝咖啡聊。

---

## 这 paper 在解决什么痛点

你训 LLM 做 math reasoning，用 RLVR。每个 prompt 让 model 生成几个 answer，对了给 +1 错了给 -1，然后用 policy gradient 更新参数。

policy gradient 长这样：`gradient = score_function × (reward - baseline)`。

baseline 这东西极其关键。它是你判断"这个 answer 是好是坏"的参照系。如果 baseline 估错了，你就在告诉 model 错误的方向 —— 一个本来该被鼓励的 answer 可能被惩罚，反之亦然。

问题是：**真正的 baseline（这个 prompt 在当前 policy 下的平均 reward）你算不出来**，因为生成空间太大，没法穷举。

所以大家用两种近似：

**第一种是 GRPO 的办法**：让 model 对同一个 prompt 生成 16 个 answer，取它们的平均 reward 当 baseline。这叫 empirical mean。好处是无偏的，坏处是 16 个样本方差太大。尤其 long reasoning task，生成 16 个 4096 token 的 answer 算不动，你可能只生成 4 个，那这 4 个的平均值噪声极大 —— 偶尔抽到全对或全错，baseline 就飘了。

**第二种是 PPO 的办法**：单独训一个 value model 去预测 baseline。好处是方差小，坏处是这个 value model 得跟着 policy 同步训，policy 每次变它就得跟，否则就 OOD 了。训 critic 的开销很大，而且 critic 本身也会在没见过的 prompt 上瞎预测。

所以这是个两难：要么 unbiased 但 noisy，要么 stable 但 biased。

---

## V0 是什么

V0 是这篇 paper 的前作。核心 idea：不要让 value model 跟 policy 同步训了，而是用一个 **frozen 的、独立预训练好的 generalist value model**。

怎么让它知道当前 policy 的能力？把 policy 最近在哪些 prompt 上得了什么分，作为一个 in-context set 喂给它。它读到这些（prompt, reward）对，就知道"哦这个 policy 大概在这个难度水平"，然后给新 prompt 预测一个 baseline。

这样 value model 完全 decouple，不用梯度更新，零成本。

**但 V0 有问题**：它在没见过的 prompt 上会 hallucinate。预测出来一个 baseline 可能完全不对。如果你直接把它当 baseline 用，policy 就被一个错误的锚带偏了。

---

## V0.5 的核心 idea

V0.5 干的事就是：**用 V0 的预测当一个 prior，但不要无脑信它，用一个统计测试来判断它可不可靠，不可靠就退回到 empirical mean**。

具体来说：

1. 先让 V0 给一个预测 $V$
2. 让 policy 生成 4 个 rollout，算 empirical mean $\bar{v}_4$
3. 看 $V$ 和 $\bar{v}_4$ 差多远
4. 如果差得在"4 个样本的正常噪声范围内"（$|\bar{v}_4 - V| \leq 1/\sqrt{4} = 0.5$），那认为 V0 是对的，差的那点波动是 sampling noise，**信 V0**
5. 如果差得超过这个范围，那 V0 大概率 hallucinate 了，**信 empirical mean**
6. 中间状态：按比例混合两者

这个"按比例混合"就是 shrinkage estimator —— 经典统计学工具。混合的权重是 $\Delta^2 / (\Delta^2 + \sigma^2)$，也就是 prior 的 bias 平方占总误差的比例。prior 越准，权重越偏向 prior；prior 越离谱，权重越偏向 empirical。

---

## 为什么这样做是对的

这里有个非常关键的数学事实，是整篇 paper 的灵魂。

policy gradient 的方差，可以被分解成三部分：

1. **Oracle variance**：即使 baseline 完美，reward 本身有随机性，这部分消不掉
2. **MSE propagation term**：baseline 的 MSE，被一个叫 $\Phi_{\text{score}}$ 的东西放大
3. **Bias cross term**：baseline 的 bias 引入的扰动

$\Phi_{\text{score}}$ 是 score function 的期望平方范数，对几十亿参数的 LLM 来说，这是个天文数字。

**这就意味着**：baseline 的 MSE 哪怕只有一点点，乘上 $\Phi_{\text{score}}$ 后都会变成巨大的 gradient variance。所以 MSE 是真正的杀手，bias 反而是次要的（因为 bias 的系数 $L$ 远小于 $\Phi_{\text{score}}$）。

GRPO 在 sparse rollout 下崩溃，就是因为 empirical mean 的 MSE 太大（虽然 unbiased），被 $\Phi_{\text{score}}$ 放大后 gradient 炸了。

V0.5 的策略就是：**主动引入一个小小的、有界的 bias（最多 $1/\sqrt{k}$），换取 MSE 的大幅下降**。因为 MSE 的系数 $\Phi_{\text{score}}$ 远大于 bias 的系数 $L$，这笔交易是赚的。

而且这个 bias 是有界的：V0.5 的 estimator 的 bias 不会超过 $1/\sqrt{k}$，这正好等于纯 empirical mean 本身的 standard error。所以最坏情况下 V0.5 不会比 GRPO 更糟，但好情况下 MSE 能大幅降低。这是 free lunch。

---

## 动态 budget 是怎么回事

光做 shrinkage 还不够。4 个样本下，你判断 V0 可不可靠，可能判错 —— V0 其实是对的，但 4 个样本恰好抽到了极端值，看起来 V0 错了。这是 false rejection。

V0.5 的解决方案是 **sequential testing**：

如果 4 个样本测出来 V0 可信，那就用 4 个样本，省 compute。

如果测出来 V0 不可信，不要立刻下结论，而是再采 2 个，重新算。样本多了噪声小了，判断更准。

那要采到什么时候停？这就有个 stopping rule：

$$K^* = \frac{1}{\sqrt{c}} - \frac{1}{\hat{\Delta}^2}$$

- $c$ 是单次 rollout 的 compute cost，是个小常数（paper 里取 0.0039）
- $1/\sqrt{c}$ 是最大预算上限（约 16）
- $1/\hat{\Delta}^2$ 是"V0 的可信度惩罚"

如果 V0 很可信（$\hat{\Delta}^2 \to 0$），惩罚项巨大，$K^*$ 很小，早停省算力。

如果 V0 严重 hallucinate（$\hat{\Delta}^2$ 大），惩罚项小，$K^* \to 16$，多采来纠正。

这是一个 **feedback control** 机制：实时看 V0 和 observation 的冲突程度，动态决定要不要多花 compute。

---

## 为什么是 4 个样本起步

这是个非常细致的工程考量。

binary reward 下，$k$ 个 rollout 的 empirical mean 只能取 $2x/k - 1$ 这些离散值（$x$ 是成功次数）。相邻值的间隔是 $2/k$。

而你的测试阈值是 $1/\sqrt{k}$。

要保证"单次 rollout 的噪声不会让 mean 跳过整个测试区间"，需要：

$$\frac{1}{\sqrt{k}} \geq \frac{2}{k} \implies k \geq 4$$

$k = 1, 2, 3$ 时，离散 gap 太大，单次随机波动就会触发误判，系统不稳定。$k = 4$ 是临界点。

实验也验证了：$k = 1, 2$ 训练崩溃，$k = 4$ 就能 work。

---

## 实验结果讲了什么

1. **性能**：6 个 math benchmark 上比 GRPO 和 DAPO 都好，快收敛 + 10% 提升。这不是一点点提升，是显著提升。

2. **Gradient norm**：V0.5 的 gradient norm 更低更稳。直接印证了"MSE 是 gradient variance 的放大器"这个理论。GRPO 在 sparse 下 gradient 飘得厉害。

3. **Policy entropy**：V0.5 的 entropy 保持得更高。GRPO 的 entropy 快速衰减，因为高噪声 gradient 把 model 推进 local optima。V0.5 用低噪声 baseline 让 model 能 sustained exploration。

4. **Extreme sparsity**：即使固定 $k = 4$ 不用动态 budget，纯 shrinkage 就能超过 $G = 16$ 的 GRPO。说明 shrinkage 本身就值钱，动态 budget 是锦上添花。

---

## 一句话总结

**与其追求 unbiased 但 noisy 的 baseline，不如用一个 frozen 的 generalist value model 当 prior，然后用统计测试实时判断它可不可信，可信就信它抑制 variance，不可信就退回 empirical mean，中间状态按比例混合。再用 sequential testing 动态决定要不要多采样本纠正 prior 的错误。**

核心 trade：用一个有界的 bias 换 MSE 的大幅下降。在 LLM RL 这个 $\Phi_{\text{score}}$ 巨大的场景下，这是正确的 trade。

---

## 为什么我觉得这 paper 优雅

它把几个经典统计学工具（James-Stein shrinkage、positive-part truncation、Wald sequential analysis、Hoeffding bound）非常干净地 import 到 LLM RLVR 里，每个工具都对应一个具体的工程问题，而且每个 choice 都有 tight 的理论 bound。

更妙的是，它不是把 V0 当 oracle，而是当 prior —— 一个可能错的信息源。这种"承认 prior 会错，但用机制控制错的代价"的设计哲学，比单纯"信 prior"或"不信 prior"都更鲁棒。

如果你要 build intuition，记住一句话：**在 LLM RL 中，baseline 的 MSE 比 bias 更重要，因为 score function 的范数太大，MSE 被放大成 gradient variance**。所有 trick 都围绕这个事实展开。

# $V_{0.5}$: Generalist Value Model as a Prior for Sparse RL Rollouts 深度解读

非常高兴能和你（Andrej）一起拆解这篇paper。这篇工作的核心 insight 紧扣了你以前在 reinforcement learning for LLM 上多次强调的一个痛点：**在 sparse rollout regime 下，baseline 的 MSE 才是 policy gradient 稳定性的真正杀手**。作者用一套 statistical shrinkage + sequential testing 的组合拳把这件事做得很优雅。我下面把数学、直觉、工程实现都拆开讲。

---

## 1. Problem Setup：为什么 baseline 这件事在 LLM RLVR 里这么难

在 RLVR（Reinforcement Learning with Verifiable Rewards）里，policy gradient 的形式是：

$$
\hat{g}(\theta) = \nabla_\theta \log \pi_\theta(o \mid x) \cdot (r - \mu)
$$

变量说明：
- $x \in \mathcal{D}_{\text{prompt}}$：输入 prompt
- $o \sim \pi_\theta$：policy 生成的 response
- $r \in \{-1, 1\}$：rule-based verifier 给的 normalized binary reward
- $\mu$：baseline，理论最优值是 $\mu_{\text{true}} = \mathbb{E}_{o \sim \pi_\theta}[r \mid x]$（Eq. 1）
- $A = r - \mu$：advantage

**核心难点**：$\mu_{\text{true}}$ 在 LLM 巨大生成空间上没法算，所以只能 approximate。两条主流路径都有硬伤：

| 范式 | 例子 | Bias | Variance | 计算成本 |
|------|------|------|----------|----------|
| Parameterized Value Model | PPO（[Schulman 2017](https://arxiv.org/abs/1707.06347)） | 容易 OOD systematic bias | 低 | 需要 synchronously train critic |
| Empirical Group Sampling | GRPO（[Shao 2024](https://arxiv.org/abs/2402.03300)） | 0（unbiased） | $\propto 1/G$，sparse 时爆炸 | 需要 large $G$ |

在 long-horizon reasoning 任务上，大 $G$ 算不动，sparse rollout（$G = 4$ 之类）下 GRPO 的 empirical mean $\bar{v}_G = \frac{1}{G}\sum_{k=1}^G r_k$（Eq. 2）会被噪声严重污染。

---

## 2. $V_0$：Generalist Value Model 的回顾

$V_0$（[Zhang 2026](https://arxiv.org/abs/2602.03584)）的关键 trick 是：把 policy 的 capability 用 **in-context set** 显式表示，而非隐式编进 weights。

$$
V = V_0(x, \mathcal{C}_\pi), \quad \mathcal{C}_\pi = \{(x_i, r_i)\}_{i=1}^N
$$

变量说明：
- $\mathcal{C}_\pi$：policy $\pi$ 的 historical query-performance pairs（capability context）
- $V_0$：frozen, separately pre-trained 的 generalist value model
- 输出 $V$：在 rollouts 之前就能给的 prior prediction

这样 critic 不用跟着 policy 同步更新，**decouple 了 value estimation 和 policy evolution**。$V_0$ 的架构（paper §4.1.1）：
1. Semantic-Perception Backbone：frozen Qwen3-Embedding-0.6B（$d_{\text{embed}}=1024$）
2. Residual Query Adapter：168 static queries，projection dim=6，3 个 MHA layer
3. Probabilistic In-Context Head：用 TabPFN（[Hollmann 2022](https://arxiv.org/abs/2207.01848)）做 single-pass Bayesian inference

**但 $V_0$ 直接当 baseline 有问题**：在 OOD prompt 上会 hallucinate。这就引入了 prior bias：

$$
\Delta^2 = (V - \mu_{\text{true}})^2
$$

这是 Eq. 4。Prior variance 是 0（deterministic），但 bias 可能很大。

---

## 3. $V_{0.5}$ 的核心 idea：Shrinkage + Sequential Testing

直觉是：**当 prior 可信时多用 prior 抑制 variance，当 prior 与 observation 显著冲突时退回 empirical mean**。这是一个经典的 James-Stein shrinkage estimator 思想（[James & Stein 1961](https://projecteuclid.org/euclid.bsmsp/1200512173)）的 online 版本，再叠一个 sequential testing 来动态分配 budget。

### 3.1 Unified Advantage Formulation（Eq. 5）

$$
A_i = r_i - \underbrace{(w \cdot \bar{v}_k + (1-w) \cdot V_0(x, \mathcal{C}_\pi))}_{\text{Fused Shrinkage Baseline } \mu^*}
$$

变量：
- $w \in [0, 1]$：shrinkage weight，自适应
- $\bar{v}_k$：$k$ 次 rollout 的 empirical mean
- $V_0(x, \mathcal{C}_\pi)$：prior prediction

对比三种 baseline：
- PPO：$A_i = r_i - V_\phi(x)$，需要 train critic
- GRPO：$A_i = r_i - \frac{1}{G}\sum_k r_k$，unbiased 但 noisy
- $V_{0.5}$：convex combination，adaptive tradeoff

---

## 4. Theorem 3.1：为什么 MSE 比 Bias 更重要

这是整篇 paper 的 theoretical cornerstone，我详细拆 proof（paper A.2）。

设 single-step policy gradient estimator：$\hat{g}(\theta) = \nabla_\theta \log \pi_\theta(o \mid x)(r - \mu)$。

由于 $\mu$ 与当前 action $o$ 独立，baseline 不破坏 unbiasedness：$\mathbb{E}[\hat{g}(\theta)] = g_{\text{true}}$。

$$
\text{Tr}(\text{Var}(\hat{g}(\theta))) = \mathbb{E}_{o,\mu}[\|\hat{g}(\theta)\|^2] - \|g_{\text{true}}\|^2
$$

展开 $(r - \mu)^2$：

$$
(r - \mu)^2 = (r - \mu_{\text{true}})^2 + (\mu_{\text{true}} - \mu)^2 + 2(r - \mu_{\text{true}})(\mu_{\text{true}} - \mu)
$$

代入平方项，因为 score function $\nabla_\theta \log \pi_\theta(o \mid x)$ 与 $\mu$ 独立，分解成三项：

**Term 1: Oracle variance**
$$
\mathbb{E}_o\left[\|\nabla_\theta \log \pi_\theta(o \mid x)\|^2 (r - \mu_{\text{true}})^2\right] = \text{Var}_{\text{oracle}}
$$

**Term 2: MSE propagation**
$$
\mathbb{E}_{o,\mu}\left[\|\nabla_\theta \log \pi_\theta(o \mid x)\|^2 (\mu_{\text{true}} - \mu)^2\right] = \Phi_{\text{score}} \cdot \text{MSE}(\mu)
$$

其中 $\Phi_{\text{score}} = \mathbb{E}_o[\|\nabla_\theta \log \pi_\theta(o \mid x)\|^2]$。

**Term 3: Bias cross-perturbation**
$$
2 \mathbb{E}_{o,\mu}\left[\|\nabla_\theta \log \pi_\theta(o \mid x)\|^2 (r - \mu_{\text{true}})(\mu_{\text{true}} - \mu)\right] = L \cdot |\text{Bias}(\mu)|
$$

合起来得到 Theorem 3.1：

$$
\boxed{\text{Tr}(\text{Var}(\hat{g}(\theta))) \leq \text{Var}_{\text{oracle}} + \Phi_{\text{score}} \cdot \text{MSE}(\mu) + L \cdot |\text{Bias}(\mu)|}
$$

**关键 insight**：对几十亿参数的 LLM，$\Phi_{\text{score}}$ 本身就是天文数字。所以 baseline MSE 上的微小误差都会被 $\Phi_{\text{score}}$ 巨幅放大成 gradient variance 爆炸。这给出 $V_{0.5}$ 的设计哲学：**用一个 bounded 的 bias 换一个 massive 的 MSE 减少**。

---

## 5. Empirical Shrinkage Fusion 的推导

### 5.1 Theorem 3.2: MSE 正交分解

设 $\mu^* = w\bar{v}_k + (1-w)V$，则：

$$
\text{MSE}(w) = \mathbb{E}[(\mu^* - \mu_{\text{true}})^2]
$$

用 $1 = w + (1-w)$ 重写 $\mu_{\text{true}}$：

$$
\text{MSE}(w) = \mathbb{E}\left[\left(w(\bar{v}_k - \mu_{\text{true}}) + (1-w)(V - \mu_{\text{true}})\right)^2\right]
$$

展开：

$$
= w^2 \mathbb{E}[(\bar{v}_k - \mu_{\text{true}})^2] + (1-w)^2 (V - \mu_{\text{true}})^2 + 2w(1-w)(V - \mu_{\text{true}})\mathbb{E}[\bar{v}_k - \mu_{\text{true}}]
$$

因为 $\bar{v}_k$ 是 unbiased estimator，$\mathbb{E}[\bar{v}_k - \mu_{\text{true}}] = 0$，所以 cross term 严格为 0，得到 **正交分解**：

$$
\boxed{\text{MSE}(w) = w^2 \sigma_{\text{noise}}^2 + (1-w)^2 \Delta^2}
$$

变量：
- $\sigma_{\text{noise}}^2 = \text{Var}(\bar{v}_k)$：empirical observation variance
- $\Delta^2 = (V - \mu_{\text{true}})^2$：prior bias

注意 cross term 为 0 是因为 prior $V$ deterministic、$\bar{v}_k$ unbiased，这是 shrinkage estimator 经典性质。

### 5.2 Theorem 3.3: 最优 shrinkage weight

对 $w$ 求导：

$$
\frac{d\text{MSE}(w)}{dw} = 2w\sigma_{\text{noise}}^2 - 2(1-w)\Delta^2 = 0
$$

解出：

$$
\boxed{w^* = \frac{\Delta^2}{\Delta^2 + \sigma_{\text{noise}}^2}}
$$

二阶导 $2\sigma_{\text{noise}}^2 + 2\Delta^2 > 0$，保证全局最小。

**直觉**：
- 当 prior 完美（$\Delta^2 = 0$），$w^* = 0$，纯用 prior
- 当 prior 完全 garbage（$\Delta^2 \to \infty$），$w^* \to 1$，纯用 empirical mean
- 当 variance 主导（sparse rollout, $\sigma_{\text{noise}}^2 \gg \Delta^2$），$w^* \to 0$，更信任 prior
- 这就是 adaptive fusion 的本质：**通过 $\Delta^2 / \sigma_{\text{noise}}^2$ 比值动态切换**

---

## 6. Empirical Estimation：从理论到工程

理论 $w^*$ 依赖 $\Delta^2$ 和 $\sigma_{\text{noise}}^2$，但真实场景 $\mu_{\text{true}}$ 未知，得 estimate。

### 6.1 Guaranteed variance（Eq. 6）

因为 $r \in \{-1, 1\}$，单次 rollout variance $\leq 1$（Bernoulli 极限），所以 $\bar{v}_k$ 的 variance $\leq 1/k$：

$$
\hat{\sigma}_{\text{noise}}^2 = \frac{1}{k}
$$

这是一个 **worst-case 保证**，避免低估 noise 导致对 prior 过度自信。

### 6.2 Empirical bias with truncation（Eq. 7）

$$
\boxed{\hat{\Delta}_k^2 = \max\left(0, (\bar{v}_k - V)^2 - \frac{1}{k}\right)}
$$

这里有个非常巧妙的统计解释（paper A.4）：

设 hypothesis test：
- $H_0: \Delta^2 = 0$（prior 完全正确）
- $H_1: \Delta^2 > 0$（prior 有 bias）

在 $H_0$ 下，$\mathbb{E}[(\bar{v}_k - V)^2] = \sigma_{\text{noise}}^2 \leq 1/k$。

所以：
- **Acceptance region**：$(\bar{v}_k - V)^2 \leq 1/k$ → 认为是 noise，$\hat{\Delta}_k^2 = 0$，完全信任 prior
- **Rejection region**：$(\bar{v}_k - V)^2 > 1/k$ → 拒绝 $H_0$，估计真实 bias

这个 $\max(0, \cdot)$ truncation 等价于一个 **positive-part James-Stein estimator**，是经典 shrinkage literature 里的标准做法（[Efron & Morris 1973](https://www.jstor.org/stable/2336938)）。

### 6.3 Adaptive weight（Eq. 8 & 9）

$$
\hat{w}_k = \frac{\hat{\Delta}_k^2}{\hat{\Delta}_k^2 + \hat{\sigma}_{\text{noise}}^2} = \frac{\hat{\Delta}_k^2}{\hat{\Delta}_k^2 + 1/k}
$$

$$
\hat{\mu}^* = \hat{w}_k \bar{v}_k + (1 - \hat{w}_k) V
$$

### 6.4 Surrogate objective（Eq. 10）

用 importance sampling ratio $\rho_i(\theta) = \pi_\theta(o_i \mid x) / \pi_{\theta_{\text{old}}}(o_i \mid x)$ 和标准化 advantage $A_i = (r_i - \hat{\mu}^*) / \hat{\sigma}^*$，其中 $\hat{\sigma}^* = \sqrt{1 - \hat{\mu}^{*2}}$（Bernoulli std），clip ratio $\epsilon$：

$$
\mathcal{T}_{V_{0.5}}(\theta) = \mathbb{E}\left[\frac{1}{k}\sum_{i=1}^k \min\left(\rho_i(\theta) A_i, \text{clip}(\rho_i(\theta), 1-\epsilon, 1+\epsilon) A_i\right)\right]
$$

这是 PPO clipped surrogate 的 group-size adaptive 版本。

---

## 7. Theorem 3.4: Bias Bound（关键 safety guarantee）

这是 $V_{0.5}$ 的另一块基石。$\hat{w}_k$ 依赖 $\bar{v}_k$，所以 $\hat{\mu}^*$ 不再 unbiased。但作者证明：

$$
\hat{\mu}^* = \bar{v}_k - (1 - \hat{w}_k)(\bar{v}_k - V)
$$

bias：

$$
\text{Bias}(\hat{\mu}^*) = -\mathbb{E}\left[(1 - \hat{w}_k)(\bar{v}_k - V)\right]
$$

定义 $Z = \frac{1/k}{\hat{\Delta}_k^2 + 1/k}(\bar{v}_k - V)$，bias = $-\mathbb{E}[Z]$。

**Case 1**：$(\bar{v}_k - V)^2 \leq 1/k$（接受 $H_0$），则 $\hat{\Delta}_k^2 = 0$，$Z = \bar{v}_k - V$，所以 $|Z| \leq 1/\sqrt{k}$。

**Case 2**：$(\bar{v}_k - V)^2 > 1/k$（拒绝 $H_0$），则 $\hat{\Delta}_k^2 = (\bar{v}_k - V)^2 - 1/k$，denominator 化简为 $(\bar{v}_k - V)^2$，所以：

$$
Z = \frac{1/k}{(\bar{v}_k - V)^2}(\bar{v}_k - V) = \frac{1/k}{\bar{v}_k - V}
$$

由 $|\bar{v}_k - V| > 1/\sqrt{k}$，得 $|Z| < 1/\sqrt{k}$。

**综合**：$|Z| \leq 1/\sqrt{k}$ 几乎必然成立，所以：

$$
\boxed{|\text{Bias}(\hat{\mu}^*)| \leq \frac{1}{\sqrt{k}}}
$$

并且若 $\Delta \neq 0$，bias 以 $\mathcal{O}(1/k)$ 衰减（用 Hoeffding 不等式分 typical event 和 rare event 分析）。

**直觉**：sparse rollout 下 empirical mean 误差是 $\mathcal{O}(1/\sqrt{k})$，$V_{0.5}$ 的 bias 同样被 bound 在 $1/\sqrt{k}$，所以最坏不会比纯 GRPO 更糟；但 MSE 大幅下降。这是一个 free lunch。

## 8. Sequential OSLA Allocation：动态 budget

固定 $k$ 在极端 sparse 下可能误判 prior。$V_{0.5}$ 引入 One-Step-Look-Ahead（OSLA）sequential analysis（[Wald 2004](https://books.google.com/books?id=IxtekAEACAAJ)）做 dynamic stopping。

### 8.1 Risk function（Eq. 11）

$$
R(k) = \widehat{\text{MSE}}(k) + c \cdot k, \quad \widehat{\text{MSE}}(k) = \frac{\hat{\Delta}_k^2}{k\hat{\Delta}_k^2 + 1}
$$

变量：
- $c$：单次 rollout 的 compute cost factor
- $\widehat{\text{MSE}}(k)$：把 $\Delta^2$ 替换成 $\hat{\Delta}_k^2$ 后的 empirical MSE

### 8.2 Marginal return（Lemma 3.5）

单步边际回报：

$$
g(k) = \widehat{\text{MSE}}(k) - \widehat{\text{MSE}}(k+1) = \frac{\hat{\Delta}_k^4}{(k\hat{\Delta}_k^2 + 1)((k+1)\hat{\Delta}_k^2 + 1)}
$$

下界 envelope：

$$
g(k) > \frac{\hat{\Delta}_k^4}{((k+1)\hat{\Delta}_k^2 + 1)^2}
$$

### 8.3 Optimal stopping（Theorem 3.6 / Eq. 12）

让边际回报 = 边际成本 $c$：

$$
\frac{\hat{\Delta}_k^2}{(k+1)\hat{\Delta}_k^2 + 1} = \sqrt{c}
$$

解出：

$$
\boxed{K^* = \inf\left\{k \geq k_{\min}: k \geq \frac{1}{\sqrt{c}} - \frac{1}{\hat{\Delta}_k^2}\right\}}
$$

**直觉解读**：
- $1/\sqrt{c}$：cost 决定的 **theoretical max budget**。$c = 0.0039$ 时，$1/\sqrt{c} \approx 16$
- $1/\hat{\Delta}_k^2$：**adaptive decay penalty**
  - prior 可信（$\hat{\Delta}_k^2 \to 0$）→ penalty 巨大 → $K^*$ 小 → 早停
  - prior hallucinate（$\hat{\Delta}_k^2$ 大）→ penalty 小 → $K^* \to 1/\sqrt{c}$ → 多采

这是一种基于实时观察的 **feedback control** 机制。

---

## 9. 为什么 $k_{\min} = 4$：discrete reward 的 quantization 约束

paper A.8 给了一个非常细致的分析。binary reward $r \in \{-1, 1\}$ 下，$k$ 次 rollout 中有 $x$ 次成功时 $\bar{v}_k = 2x/k - 1$，相邻 observation 的 quantization gap：

$$
\text{Gap}(k) = \frac{2}{k}
$$

test tolerance 半径（max entropy std）：

$$
\text{Threshold}(k) = \frac{1}{\sqrt{k}}
$$

要保证 single rollout 噪声不无脑 trigger rejection，需要：

$$
\frac{1}{\sqrt{k}} \geq \frac{2}{k} \implies k \geq 4
$$

| $k$ | Gap | Threshold | 状态 |
|-----|-----|-----------|------|
| 1 | 2.0 | 1.0 | 单 rollout 噪声主导，假阳性 |
| 2 | 1.0 | 0.707 | 标准噪声触发 reject |
| 3 | 0.667 | 0.577 | 不稳定 |
| 4 | 0.5 | 0.5 | 恰好覆盖，临界 stable |

以 $V = 0.8$ 为例：
- 4/4 正确：$|1 - 0.8| = 0.2 \leq 0.5$，accept
- 3/4 正确：$|0.5 - 0.8| = 0.3 \leq 0.5$，accept

所以 $k_{\min} = 4$ 是工程上保证 statistical test 有效的下限。这也解释了 paper 中 $k \in \{1, 2\}$ 训练不收敛的实验现象。

## 10. Regret Bound（A.7）：动态调度不会爆炸

设 oracle optimal stopping step 为 $k_{\text{oracle}}^*$（知道真 $\Delta^2$），定义 regret：

$$
\text{Regret}(c) = \mathbb{E}[R(K^*)] - R(k_{\text{oracle}}^*)
$$

通过二阶 Taylor 展开：

$$
\text{Regret}(c) \approx \frac{1}{2} R''(x^*) \mathbb{E}[(K^* - x^*)^2]
$$

计算 $R''(x^*) = 2c^{3/2}$，再用 Delta method 估计 $\mathbb{E}[(K^* - x^*)^2] = \mathcal{O}(\sqrt{c})$，得：

$$
\text{Regret}(c) = \underbrace{\mathcal{O}(c^2)}_{\text{estimation}} + \underbrace{\mathcal{O}(c^{3/2})}_{\text{discretization overshoot}} + \underbrace{\mathcal{O}(c)}_{\text{renewal correlation}}
$$

因为 $c \ll 1$，最低阶 $\mathcal{O}(c)$ 主导：

$$
\text{Regret}(c) \leq \mathcal{O}(c)
$$

**直觉**：动态调度在最坏情况下多花的 compute 等价于常数次 rollout（一两次），完全可控。这给工程部署打了强心针。

## 11. 实验设置和结果解读

### 11.1 $V_0$ 的 enhanced training

- 424k 高质量训练对
- 训练数据来源：Qwen3 全系（0.6B - 30B），Base / Instruct / Thinking variant
- 每个 trajectory 200+ checkpoint，每 checkpoint 20k rollout
- 128 GPU 上 pre-train 40 小时
- Support Buffer capacity 512，每次 sample 256 pairs 做 context $\mathcal{C}_\pi$

### 11.2 算法 workflow（§4.1.3）

1. **Step 1**：从 Support Buffer sample 256 对历史 $(x_i, r_i)$ → query $V_0$ 得 prior $V \in [0, 1]$
2. **Step 2**：cold start，$k_{\text{init}} = 4$ rollouts
3. **Step 3**：假设检验
   - $(\bar{v}_4 - V)^2 \leq 1/4$ → 接受 prior，$\hat{\Delta}_k^2 = 0$，不额外采
   - 否则 → 触发 OSLA
4. **Step 4**：OSLA 分配
   - $c = 0.0039$，max budget $\approx 16$
   - $k_{\text{target}} = 1/\sqrt{c} - 1/\hat{\Delta}_k^2$
   - $k < k_{\text{target}}$ → 加 2 rollout
   - 优化：若 batch 内 <25% 样本需要更多 compute，全局停；单次 dispatch pad 到 32 的倍数（防 TP 碎片）
5. **Step 5**：最终 shrinkage fusion，$A_i = (r_i - \hat{\mu}^*)/\hat{\sigma}^*$，喂给 surrogate

### 11.3 Baseline 配置（fair comparison）

- GRPO：batch 512，$G=16$，KL 0.001
- DAPO（[Yu 2025](https://arxiv.org/abs/2503.14476)）：batch 512，$G=16$，rollout batch $512 \times 3$
- $V_{0.5}$：保证 per-step 总 compute 与 GRPO/DAPO 持平（prompt batch × group size 恒定）
- Policy: Qwen3-4B-Instruct-2507，DAPO-Math-17k dataset
- AdamW, lr=$1\times 10^{-6}$, 10 warmup, no KL, grad clip 1.0, max len 4096
- Eval：6 个数学 benchmark（AIME 2024/2025, Olympiad Bench, MATH500, Minerva Math, AMC 2023），mean@16，temperature 1.0, top-p 0.7

### 11.4 关键实验结论

**Figure 1**：6 个 benchmark 上比 GRPO/DAPO 快收敛 + 10%+ 性能提升

**Figure 3**（gradient norm evolution）：$V_{0.5}$ 的 gradient norm 显著更低且更稳定。直接印证 Theorem 3.1 — MSE 减少 → gradient variance 减少。

**Figure 4**（policy entropy）：GRPO entropy 快速 decay，$V_{0.5}$ 保持在更高水平。低噪声 gradient 让 model 不轻易 collapse 到 local optima。

**Figure 5**（extreme sparsity）：$k \in \{4, 8\}$ 的 fixed shrinkage 已经超过 $G=16$ 的 GRPO，证实 shrinkage 的核心价值。但 $k \in \{1, 2\}$ 训练崩溃，对应 §9 的 quantization 分析。

## 12. 与 Related Work 的位置感

| 方法 | 核心 trick | 与 $V_{0.5}$ 区别 |
|------|------------|--------------------|
| PPO | coupled critic | 要同步训，OOD 风险 |
| GRPO | group mean | sparse 下 high variance |
| ReMax | greedy decode baseline | 单样本，噪声大 |
| OPO | length-weighted mean | 假设 gradient orthogonal |
| MC-GRPO | median + MAD | 抗 outlier，但仍纯 empirical |

| BNPO | Beta distribution | moment estimation |
| HA-DW | Kalman filter history anchor | history-aware，但仍 data-driven |

| GiGPO | bi-level group | global + micro |
| Tree-OPO | MCTS topology | QP formulation |

$V_{0.5}$ 的独特定位是**把 prior 当 statistical anchor，用 sequential testing 控制 hallucination 风险**，本质是把 RLVR baseline estimation 变成一个 online decision problem。

## 13. Build Intuition：把整篇 paper 压成几句话

1. **MSE 是 policy gradient 的真正杀手**：因为 $\Phi_{\text{score}}$ 巨大，所以 baseline MSE 通过 $\Phi_{\text{score}} \cdot \text{MSE}$ 放大成 gradient variance。这是为什么 unbiased 但 noisy 的 GRPO 在 sparse 下崩溃。
2. **Shrinkage 是经典的 bias-variance 调控**：$w^* = \Delta^2/(\Delta^2 + \sigma_{\text{noise}}^2)$ 这个比例天然反映"信任 prior 还是信任 observation"。
3. **Truncation = hypothesis test**：$\max(0, \cdot)$ 把统计测试 baked 进 estimator，自动拒绝 hallucinated prior。
4. **Sequential OSLA**：把 budget allocation 变成实时 feedback control — prior 准就早停，prior 错就多采到修正。
5. **Bias bound $\leq 1/\sqrt{k}$**：动态 weight 引入的 bias 不会比 empirical mean 本身的 error 更糟，所以是 free lunch。
6. **$k_{\min} = 4$**：discrete reward quantization 的硬约束，binary 空间下 4 次 rollout 是统计 test 成立的下限。
7. **Regret $\leq \mathcal{O}(c)$**：动态调度在最坏情况下多花常数 rollout 的 compute，可控。

## 14. 我对 paper 的几个 open thought

1. **Bernoulli reward 假设太强**：实际 RLVR 任务很多是 sparse binary，但 multi-step reasoning 的 partial credit（如 process reward）会破坏 $r \in \{-1, 1\}$。$\sigma_{\text{noise}}^2 \leq 1/k$ 的 guaranteed bound 在 continuous reward 下不再成立，需要重新推导。作者 future work 提的 process-level $V_0$ 应该会触及这一点。

2. **Support Buffer 的 i.i.d. 假设**：$\mathcal{C}_\pi$ 是 recent 512 个 sample，但训练时 policy $\pi$ 是 non-stationary 的。$V_0$ 的 capability context 可能 lag，导致 prior 系统性偏低。Kalman filter（HA-DPO 思路）或者 EMA 加权 context 可能更好。

3. **OSLA 的 myopic 局限**：one-step look-ahead 不考虑 future policy 改变带来的 value 漂移。在 long-horizon 上可能 under-sample。Bayesian Optimal Stopping（虽然 intractable）或者 2-step lookahead 可能更稳。

4. **和 GRPO 的公平性**：实验中 GRPO 用 $G=16$，$V_{0.5}$ 用 $k_{\text{init}}=4$ 加 dynamic 到 16，但 $V_{0.5}$ 有 $V_0$ 的额外 forward cost。这个 cost 在大模型 long context 下不可忽略。paper 里没明确 isolate $V_0$ 的 wall-clock overhead。

5. **与 RLOO / VinePPO 的关系**：leave-one-out 也是一个 reduce variance 的方法，可以和 shrinkage 叠加。这两个组合起来可能进一步降 MSE。

6. **TabPFN 的 in-context size 限制**：TabPFN-v2.5 对 support set size 有上限，256 pairs 已经偏大。未来 scaling 时这会成为 bottleneck，可能需要 amortized / hierarchical 版本。
