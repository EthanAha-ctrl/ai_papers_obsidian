复杂性假设（Merrill & Sabharwal, 2023），真正的数据生成过程可能具有任意高的计算复杂度，即使是确定性的情况。

**经典CoT的局限性**：
- 经典的CoT（Chain-of-Thought）假设问题是**从左到右、自回归**生成的
- 但复杂问题的真实解决方案过程是**非线性的、迭代的、潜在的探索与验证**
- 教科书中只呈现最终证明，而**不会呈现"风车问题"的思考过程**
- 要开始生成解决方案需要**已经知道完整的方法**
## 二、Meta Chain-of-Thought (Meta-CoT) 核心理论

### 2.1 数学公式化表达

**经典CoT的概率分布**：
```
p_data(a|q) ∝ ∫ p_data(a|s₁,...,sₙ,q) × ∏ₜ₌₁ᵗ p_data(sₜ|s_ₜ,q)  dS
```

**Meta-CoT的概率分布**（关键创新）：
```
p_data(a,s₁,...,sₙ|q) ∝ ∫ p_data(a,s₁,...,sₙ|z₁,...,z_K,q) × ∏ₜ₌₁ᴷ p_data(zₜ|zₜ,q) dZ
```

**变量解释**：
- **q**: 问题
- **sₜ**: 显式的CoT步骤（t=1,...,n）
- **a**: 最终答案
- **zₜ**: **隐藏的"思维"步骤**（Meta-CoT，t=1,...,K）
- **dS, dZ**: 积分测度

**关键洞察**：复杂推理问题的真实数据生成过程是：
```
q → z₁ → ... → z_K → (s₁,...,sₙ, a)
```

而**不是**：
```
q → s₁ → s₂ → ... → sₙ → a
```

### 2.2 o1模型的实证证据

论文分析了OpenAI o1模型在HARP基准测试上的表现：

**关键发现**：
1. **低难度问题**（Level 1）：o1生成的token数与人类解决方案相当
2. **高难度问题**（Level 5）：o1生成**显著更多**token数
3. **性能差距**随着问题复杂性**扩大**

这支持了论文的核心论点：复杂问题需要**额外的Meta-CoT过程**来达到正确解决方案。

## 三、搜索作为推理的核心机制

### 3.1 推断时间计算：Best-of-N

**实验设置**：
- 基础模型：LLaMA 3.1 8B
- 训练数据集：Numina MATH
- 评估数据集：MATH-500

**关键发现**：
```
Pass@64 准确率 ≈ 85%  （对于8B模型！）
Greedy 准确率 ≈ 40%
```

**数学公式**：
```
S* = argmax{v_θ(q,S₁), ..., v_θ(q,S_K)}
```

**Scaling Law**：性能随着推理计算持续改进，验证器与生成器之间的差距持续存在。

### 3.2 从Best-of-N到一般搜索

将推理问题形式化为**马尔可夫决策过程（MDP）**：

**MDP定义** ℳ = (S, A, P, R, γ)：

- **S (状态空间)**：Sₜ = (q, s₁, ..., sₜ)，包含问题和已生成步骤
- **A (动作空间)**：aₜ₊₁ = sₜ₊₁，下一个推理步骤
- **P (转移概率)**：确定性的下一个token生成
- **R (奖励函数)**：正确解为1，否则为0
- **γ (折扣因子)**：[0,1]，平衡额外计算与奖励

### 3.3 Process Reward Models (PRM)

**PRM函数**：
```
v_θ(q, Sₜ) → [0,1]
```

**使用PRM的搜索优势**：
1. **提前终止**：当进展不佳时
2. **回溯**：重置到有希望的状态

**PRM训练目标**：
```
L_PRM = E[(y - v_θ(q,Sₜ))²]
```

**实证结果**（Table 1）：
```
方法                    | 准确率(%)
Greedy π₀            | 41.4
MCTS-α π₀ {v,ṙ}   | 51.9
MCTS-α π₁ {v,ṙ}    | 53.2
MCTS-α π₀ {v,ṙ}    | 54.1
MCTS-α π₁ {v,ṙ}    | 56.5
```

### 3.4 Scaling Laws

**联合缩放定律**：
```
Performance = f(模型大小, 训练数据, 推断时间计算)
```

**Jones (2021)在棋类游戏上的发现**：
- **训练时计算**：持续改进
- **推理时计算**：每个检查点都持续改进
- **log-log权衡**：训练时计算与推理时计算存在对数关系

**论文的关键洞察**：在足够高的认知不确定性域中，**搜索差距会持续存在**。

## 四、将搜索内化到模型中

### 4.1 效率vs超智能

**内化搜索的两个动机**：

1. **效率**：
   - 自然语言中的分支可能包含**语义相似的内容**
   - 模型可以**避免重复采样相同的步骤**
   - 论文引用例子：高级推理模型执行许多"语义相同的推理"

2. **超智能**：
   - 通过RL训练，模型可能**发现新颖的推理方法**
   - 优化的是**算法**而非特定输出
   - 可能解决符号树搜索方法无法解决的**新类别问题**

### 4.2 STaR与Meta-STaR

**STaR算法**（Zelikman et al., 2022）：
```
1. 从SFT模型生成解：â, ŜS⁽ⁱ⁾ ~ π(a,S|q⁽ⁱ⁾)
2. 过滤：保留Ŝa⁽ⁱ⁾ = a⁽ⁱ⁾的解
3. 训练目标：ℒ_STaR(π_φ) = -E_{(q,ŜS,a)~D_STaR}[-log π_φ(a,ŜS|q)]
```

**Meta-STaR扩展**：
```
D_STaR = {q⁽ⁱ⁾, ẐZ⁽ⁱ⁾, ẐS⁽ⁱ⁾}
ℒ_Meta-STaR(π_φ) = -E_{(q,ẐZ,ẐS)~D_STaR}[-log π_φ(ẐS,ẐZ|q)]
```

其中ẐZ = (Ẑz₁, ..., Ẑz_K)是搜索轨迹。

### 4.3 使用变量计算

**训练目标**（允许动态计算预算）：
```
min_θ E_{Sᵢ~π_ref(·|q), q~D_train}
[-log π_θ(S*,EOS|S_ⱼ₋₁,...,S₁,q)], j ~ Unif(1,8)
```

**实证发现**（Figure 11）：
- **Level 1**：平均生成2.45个解
- **Level 5**：平均生成5.84个解

这表明模型**学会了根据问题复杂度调整计算使用**。

### 4.4 回溯能力

**回溯训练目标**（Ye et al., 2024b）：
```
ℒ_backtrack(θ) = -E_{s₁,...,sₙ~D_train, t~Unif(1,n)}
[log π_θ(s₁,...,s_₋ₜ,[BACK],s_ₜ,...,sₙ|q)]
```

**关键发现**：50%的错误步骤率导致准确率从78%提升到94%！

**Zhang et al. (2024b)的安全回溯**：
```
ℒ(θ) = -E_{(q,S⁺,S⁻)~D_train, t~Unif(1,n')}
[log π_θ([BACK],S⁺|S_₋ᵗ,q) + log π_θ(S⁺|q)]
```

其中S⁺是安全解，S⁻是不安全解。

### 4.5 先进推理系统的内搜索证据

**o1模型的行为分析**（Figure 14）：
1. **不一致的逻辑流**：连续步骤逻辑上不延续前一个状态
2. **语义回溯**：频繁返回到同一逻辑点
3. **重复**：模型经常重复逻辑步骤

**DeepSeek R1**：额外的自我评估步骤，结合"生成性验证"（Generative Verifier）

**Gemini 2.0 Flash Thinking**：
- 更平滑的逻辑流
- 更少的突然回溯
- 经常完全从头重新生成解决方案

**MCTS vs A*搜索轨迹**（Figure 15）：
- MCTS：更多的回溯和重复
- A*：更一致的推理流，回溯集中在关键步骤

## 五、Meta Reinforcement Learning框架

### 5.1 Meta-RL与标准RL的区别

**标准RL问题**（Ghosh et al., 2021 Remark 5.2）：
标准RL训练的策略在新任务上可能有**任意低的性能**。

**Meta-RL目标**：
```
min_θ E_{q~D_train} E_{S_ⱼ~π_θ(·|S_ⱼ₋₁,...,S₁,q)}[ℒ(q,ξ)]
```

其中ξ是适应参数，ℒ是与任务q相关的损失。

### 5.2 RL²目标函数

**E-RL²**（Stadie et al., 2019）：
```
max_θ E_{q~D_train} E_{S_ⱼ~π_θ(·|S_ⱼ₋₁,...,S₁,q)}[ℒ(q)]
```

只优化**最终回合**的奖励，允许在前K-1回合中探索而无需奖励监督。

### 5.3 q-STaR目标

论文推导了**无需外部验证器**的self-STaR变体：

**STaR变体推断**（Singh et al., 2024）：
```
log π_data(S|Z,q) = log ∫ π(S|Z,q)π(Z|q)dZ
log π(S|Z,q) = log E_{Z~π(Z|q)}[log π(S|Z,q)]
```

**VAE形式化**：
```
max_θ E_{Z~π_θ(·|q), S,q~D_train}
[log π_θ(S|Z,q) - β D_KL[π_θ(·|Z,q)||π_ref(Z|q)]]
```

**参数解释**：
- **β**：VAE正则化强度
- **D_KL**：KL散度
- **π_ref**：参考策略（instruction-tuned模型）

### 5.4 折扣率的影响

**Discounted目标**：
```
max_θ E_{S,Z~π_θ(·|q), q~D_train}
[ᾞ|Z| ẐZ* × (S,q) - β ∑ₜ₌₁ᴷ D_KL[π_θ|ᐙ(zₜ₊₁|Zₜ,q)||π_ref(zₜ₊₁|Zₜ,q)]]
```

**折扣率分布**：ᾞ ~ Uniform(1, ..., ᾞ_max)

**效果**（Figure 27）：
- **无折扣**：性能持续随采样改进
- **有折扣(γ=0.99)**：出现"驼峰"形状的目标边界

**控制模型行为的推理时提示**：
```
p_ᾞ = "Work as quickly as possible"  (高折扣率)
p_ᾞ = "Take as much time as needed"  (低折扣率)
```

- 提取boxed答案
- 过滤多选题

- 移除MATH-500测试集问题

**Strict Filter**用于Meta-RL：
- 开放性问题表述
- 可验证解
- 封闭形式答案
