从稀疏位姿图像集合重建大规模3D场景（几何、外观和语义）, VoxSplat表示
最少3张非重叠图像, 1024³体素网格, 20秒内生成数百万个高斯.
重建内容：几何+外观+语义

| 方法类型              | 代表工作                           | 局限性                          |
| ----------------- | ------------------------------ | ---------------------------- |
| **辐射场方法** (NeRFs) | NeRF [31]                      | 需要每个场景优化，无法在输入视图外重建，需要密集视图覆盖 |
| **深度学习方法**        | PixelNeRF [66], PixelSplat [4] | 只能处理低分辨率的单个对象，存在多层表面或Janus问题 |

挑战
1. **稀疏视图问题**：输入图像之间几乎没有重叠
2. **大规模场景**：需要处理数百米范围的高分辨率场景
3. **实时性要求**：需要在短时间内完成重建
4. **几何一致性**：需要保证重建的3D结构在不同视角下一致

SCube采用**两阶段重建框架**，可以用概率分布表示：

```
p(G,A|I) = p(A|G,I) · p(G|I)
```

其中：
- `I = {I_i}` : N张稀疏输入图像集合
- `G` : 场景几何表示（稀疏体素网格）
- `A` : 场景外观表示（VoxSplats + 天空全景图）

### 3.2 第一阶段：体素网格重建

#### 3.2.1 XCube骨干网络

XCube 是一个3D生成模型，能够产生高质量的对象和大规模室外场景样本。其核心特点：

- 使用**分层Latent DiT**生成sparse voxel层次结构
- 基于稀疏卷积神经网络实现
- 可以生成高达1024³分辨率的几何结构

#### 3.2.2 图像条件生成

为了将输入图像的条件信息注入到3D空间，基于DINO-v2特征提升的策略.

```
1. 使用预训练DINOv2模型提取输入图像的视觉特征
2. 通过可训练的2D卷积层将特征通道维度降至C+D
3. 将每个像素j和输入图像索引i的特征分成两部分：
   - C维规则特征: F_ij^c
   - D维Softmax归一化向量: θ_ij (表示深度的分布)
```

**深度量化特征提升公式**：

$$F_{ij}^d = \theta_{ij}^d \cdot F_{ij}, \quad C_v = \sum_{(i,j,d)} F_{ij}^d \in \mathbb{R}^C \quad (1)$$

**变量解释**：
- `F_{ij}^d` : 第i张图像第j个像素在第d个深度桶的特征
- `θ_{ij}^d` : 深度权重，可以看作对应像素深度的分布
- `C_v` : 体素v的累积特征
- `D` : 深度桶的数量，将深度范围从z_near到z_far量化为D个bin
- `v` : 体素索引
- `d ∈ [1,D]` : 深度桶索引

**深度范围量化**：

深度范围 `[z_near, z_far]` 被均匀量化为D个桶，每个桶代表一个深度区间。

#### 3.2.3 训练损失函数

$$L = L_{\text{Diffusion}} + \lambda L_{\text{Depth}} \quad (2)$$

$$L_{\text{Depth}} = \mathbb{E}_{X,i,j}[\text{Focal}(\theta_{ij}, [\theta_{ij}]_{gt})] \quad (2.1)$$

**变量解释**：
- `L_Diffusion` : 扩散模型的标准训练损失
- `L_Depth` : 多类别Focal损失 [26]，用于显式监督深度权重
- `λ` : 平衡权重超参数
- `[θ_ij]_gt` : 真值深度分布
- `Focal(·)` : 多类别Focal损失函数，用于处理类别不平衡问题

**为什么使用Focal Loss？**
Focal Loss通过降低简单样本的权重，使模型更关注困难样本，这在深度估计中特别有用，因为远处的物体和细节往往更容易被忽略。

### 3.3 第二阶段：外观重建

#### 3.3.1 VoxSplat表示

VoxSplat是本文的核心创新，它将3D高斯与体素网格相结合。Gaussian Splatting [22]将场景外观建模为高斯的和：

$$G(x) = \text{RGB} \cdot \alpha \cdot e^{-\frac{1}{2}(x-\mu)^T \Sigma^{-1} (x-\mu)} \quad (3)$$

**变量解释**：
- `α ∈ [0,1]` : 不透明度
- `μ ∈ ℝ³` : 高斯中心
- `Σ = RSS^T R^T ∈ ℝ^{3×3}` : 协方差矩阵
- `R` : 旋转矩阵，由四元数q参数化
- `S = diag(s)` : 对角尺度矩阵
- `RGB` : 颜色值

**协方差矩阵分解**：

$$\Sigma = R S S^T R^T$$

这种分解确保了协方差矩阵的正定性。

**与原始Gaussian Splatting的区别**：
- 原始方法：使用启发式规则优化高斯位置
- VoxSplat：使用前馈模型预测每个体素内的M个高斯
- 限制：高斯位置被限制在其支撑体素的邻域内

#### 3.3.2 高斯参数预测

网络输出（每个体素v）：

$$\{[\bar{\mu}_v, \bar{\alpha}_v, \bar{s}_v, \bar{q}_v, \text{RGB}_v] \in \mathbb{R}^{14}\}^M$$

**激活函数**：

$$\mu_v = r \cdot \tanh(\bar{\mu}_v) + \text{Center}_v, \quad \alpha_v = \text{sigmoid}(\bar{\alpha}_v), \quad s_v = \exp(\bar{s}_v), \quad R_v = \text{quat2rot}(\bar{q}_v) \quad (4)$$

**变量解释**：
- `Center_v` : 体素v的质心
- `r` : 超参数，控制高斯在支撑体素内的范围（设置为体素大小的3倍）
- `M` : 每个体素预测的高斯数量（最终设置为4）
- `tanh(·)` : 双曲正切函数，将值限制在[-1, 1]范围
- `sigmoid(·)` : Sigmoid函数，将值限制在[0, 1]范围
- `exp(·)` : 指数函数，确保尺度为正
- `quat2rot(·)` : 四元数到旋转矩阵的转换函数

#### 3.3.3 天空全景图背景表示

为了捕获预测几何之外的外观，模型构建了一个天空特征全景图：

$$L \in \mathbb{R}^{H_p \times W_p \times C_p}$$

**变量解释**：
- `H_p, W_p` : 全景图的高度和宽度
- `C_p` : 特征通道数

**渲染流程**：

1. 对于全景图L中的每个像素，获取其在单位球上的笛卡尔坐标P = (x, y, z)
2. 将P投影到图像平面以检索图像特征
3. 由于只有视向决定天空颜色，在投影步骤中将相机姿态的平移部分设为零
4. 应用天空掩码确保全景图只关注天空区域

**合成公式**：

$$I_{\text{pred}}(u,v) = I_{\text{GS}}(u,v) + (1-T(u,v)) \cdot I_{\text{bg}}(u,v) \quad (5)$$

**变量解释**：
- `I_GS(u,v)` : 高斯光栅化渲染的前景图像
- `I_bg(u,v)` : 从天空全景图解码得到的背景图像
- `T(u,v)` : 高斯的累积透射率图
- `(u,v)` : 像素坐标

#### 3.3.4 训练损失

$$L = \lambda_1 L_1(I_i^{\text{pred}}, I_i^{\text{gt}}) + \lambda_2 L_1(T_i, M_i) + \lambda_{\text{SSIM}} L_{\text{SSIM}}(I_i^{\text{pred}}, I_i^{\text{gt}}) + \lambda_{\text{LPIPS}} L_{\text{LPIPS}}(I_i^{\text{pred}}, I_i^{\text{gt}}) \quad (6)$$

**变量解释**：
- `I_i^gt` : 训练集的真实图像
- `M_i` : 天空掩码
- `I_i^pred` : 预测的渲染图像
- `T_i` : 预测的透射率图
- `L_1(·)` : L1损失
- `L_SSIM(·)` : 结构相似性损失 [58]
- `L_LPIPS(·)` : 学习感知图像块相似性损失 [72]

## 四、数据处理流程

### 4.1 基于Waymo Open Dataset的数据处理管道

#### 步骤1：LiDAR点云累积
- 在世界空间中累积LiDAR点
- 移除动态物体（车辆、行人等）边界框内的点
- 为每个累积的LiDAR点获取语义标签
- 未标注的点被分配其最近标注邻居的语义

#### 步骤2：多视图立体重建
- 使用COLMAP [43]中的MVS算法从图像重建密集3D点云
- 使用Segformer [62]获取点的语义标签

#### 步骤3：动态物体补偿
- 根据目标帧的边界框为动态物体添加点样本
- 获得静态和累积的真实数据用于训练

#### 场景裁剪
对于每个数据样本，将点云裁剪为以随机采样的自车姿态为中心的 **102.4m × 102.4m** 局部块。由于Waymo数据集没有后视相机，向前进方向分配更多空间。

## 五、实验评估

### 5.1 评估协议

**任务**：新视角合成

**输入**：时间戳T的多视图图像
**输出**：未来时间戳T+5和T+10的新视角渲染

**评估指标**：
- **PSNR** (Peak Signal-to-Noise Ratio) : 峰值信噪比，越高越好
- **SSIM** (Structural Similarity Index Measure) : 结构相似性指数，越高越好
- **LPIPS** (Learned Perceptual Image Patch Similarity) : 学习感知图像块相似性，越低越好

**评估设置**：
- 排除T+5和T+10评估中的移动物体区域
- 计算指标时只使用三个前视图

### 5.3 定性结果分析

**各基线方法的局限性**：

1. **PixelNeRF**：受限于网络表示能力，无法捕获场景的高频细节
2. **PixelSplat**：高度依赖输入视图的重叠区域，无法适应稀疏视图设置，无法建模真实的3D几何结构
3. **MVSplat / MVSGaussian**：基于多视图立体视觉的方法无法实现极端新视角合成（如鸟瞰图）
4. **DUSt3R**：虽然能够学习图像域中的合理位移，但仍存在缺失区域、错位或不准确深度边界

**SCube的优势**：
- 能够重建远离输入区域的完整场景几何
- 准确且一致
- 产生高质量的新视角渲染

### 5.4 几何质量评估

引入了**体素Chamfer距离**来衡量几何质量：

$$\text{Voxel Chamfer Distance} = \frac{\text{L2-Chamfer距离(预测体素, 真实体素)}}{\text{体素大小}}$$

**结果**：
- 90%的测试样本中，预测的体素网格与真实值仅相差不到**0.5个体素**

## 六、应用

### 6.1 协助Gaussian Splatting初始化

SCube创建的场景级3D高斯可用于初始化大规模3D Gaussian Splatting [22] 训练。这在SfM可能因稀疏视角而失败的室外驾驶场景中特别有用。

**初始化方法比较**：

| 初始化方法 | R=10 PSNR ↑ | R=10 SSIM ↑ | R=10 LPIPS ↓ |
|-----------|------------|------------|-------------|
| Random | 21.66 | 0.72 | 0.38 |
| Metric3Dv2 [18] | 23.30 | 0.75 | 0.33 |
| **SCube (Ours)** | **24.10** | **0.77** | **0.32** |

**变量解释**：
- `R` : 用于初始化的帧数

### 6.2 一致的LiDAR仿真

SCube可以生成一致的LiDAR点云序列，这对于自动驾驶系统的训练和验证非常重要。

**特点**：
- 仿真序列能够有效覆盖远离输入相机位置的长距离
- 能够解决复杂的几何结构，如建筑物、树木或杆子
- 保持时间一致性

### 6.3 文本到场景生成

结合文本到图像模型，SCube可以生成符合文本提示的3D场景和外观。

## 七、消融研究

### 7.1 图像条件策略

将Eq(1)中描述的图像条件策略替换为将相同特征广播到像素射线上的所有体素的平凡方案：

- 最终细级别体素网格的IoU从 **34.31%** 下降到 **30.33%**
- 考虑体素语义预测准确性的mIoU从 **20.00%** 下降到 **16.61%**

这证明了我们的条件策略能够有效消除不同深度体素的歧义性。

### 7.2 两阶段重建

使用同时预测稀疏体素和外观的单阶段模型（使用真实1024³体素网格作为输入）：

- PSNR/LPIPS：17.88/0.57（单阶段） vs 19.34/0.48（两阶段）
- 几何质量：Chamfer距离最高差100倍

### 7.3 外观重建

**体素网格分辨率和每个体素的高斯数量M的影响**：

| 分辨率 | M | PSNR ↑ | LPIPS ↓ |
|--------|---|--------|---------|
| 256³ | 4 | 18.58 | 0.62 |
| 1024³ | 4 | 19.34 | 0.48 |
| 1024³ | 1 | 19.34 | 0.48 |

**结论**：
- 高分辨率体素网格对于捕获详细几何至关重要
- 使用更多的高斯仅略微提高性能
- 最终设置M = 4

## 八、后处理

### 8.1 GAN后处理（SCube+）

直接从外观模型渲染的新视角有时会体素化伪影或噪声。作者使用可选的轻量条件GAN来解决此问题：

- 输入：渲染的图像
- 输出：精炼版本
- 判别器：从输入稀疏视图图像采样的256×256图像块，以及以渲染图像为条件的生成图像
- 训练时间：约20分钟（每个场景独立）

## 九、技术关联与延伸思考

### 9.1 与相关工作的关系

| 方法 | 关系 |
|------|------|
| **NeRF [31]** | SCube用VoxSplat替代了体辐射场，实现了快速前馈推理 |
| **Gaussian Splatting [22]** | SCube将高斯限制在体素脚手架上，无需启发式优化 |
| **XCube [39]** | SCube扩展了XCube，添加了多视图图像条件并预测外观 |
| **DUSt3R [56]** | SCube直接在3D空间中学习和表示几何，而不是在图像域 |
| **LSS [36]** | SCube的深度加权特征提升策略受到LSS启发 |

### 9.2 潜在改进方向

1. **动态场景处理**：当前方法无法处理极端光照或天气条件下的复杂动态场景
2. **遮挡区域外观**：遮挡区域的外观质量仍存在不确定性
3. **训练数据依赖**：方法仍需要真实3D训练数据
4. **视图相关外观**：当前使用0阶SH，可以探索高阶SH以实现视图依赖

### 9.3 架构图解析

```
输入图像 → DINOv2特征 → 深度加权提升 → 3D体素特征
                                    ↓
                            XCube扩散模型
                                    ↓
                            稀疏体素网格G
                                    ↓
                            3D Sparse Conv U-Net
                                    ↓
                            VoxSplat (M个高斯/体素)
                                    ↓
                            天空全景图 + 高斯渲染 → 最终图像
```

## 十、总结

SCube通过引入VoxSplat表示，成功解决了从稀疏视角图像重建大规模3D场景的挑战。其主要贡献包括：

1. **VoxSplat表示**：将3D高斯与稀疏体素网格结合，实现了高效的前馈推理
2. **深度加权特征提升**：通过学习深度分布，实现了精确的3D条件注入
3. **两阶段重建**：分离几何和外观重建，充分利用不同模型的优势
4. **实际应用**：支持LiDAR仿真、文本到场景生成等多种应用

**关键创新点**：
- 在真实3D空间中直接学习和表示几何
- 使用高分辨率稀疏网格实现大规模场景重建
- 在20秒内从3张非重叠图像生成百万级高斯

这种方法在自动驾驶、机器人、增强现实等领域有广泛的应用前景，特别是在需要快速从少量图像重建大规模3D场景的场景中。
