# 概率分布距离度量方法详解

这些是衡量两个 probability distribution 之间差异的核心方法，在 machine learning、statistics 和 information theory 中至关重要。

---

## 1. Total Variation Distance (TV)

### Definition
对于两个 probability measures P 和 Q，**Total Variation distance** 定义为：

$$TV(P, Q) = \sup_{A \in \mathcal{F}} |P(A) - Q(A)|$$

其中：
- $\sup$：上确界（supremum），即所有可能值中的最小上界
- $A$：measurable set（可测集）
- $\mathcal{F}$：σ-algebra（σ-代数），即所有 measurable sets 的集合
- $P(A), Q(A)$：分别为 P 和 Q 在集合 A 上的概率值

### 等价形式
对于 discrete distributions：

$$TV(P, Q) = \frac{1}{2} \sum_{x \in \mathcal{X}} |P(x) - Q(x)|$$

对于 continuous distributions：

$$TV(P, Q) = \frac{1}{2} \int_{\mathcal{X}} |p(x) - q(x)| \, dx$$

其中：
- $\mathcal{X}$：sample space（样本空间）
- $p(x), q(x)$：分别为 P 和 Q 的 probability density functions (PDF)

### 关键性质

| 性质 | 描述 |
|------|------|
| **Symmetry** | $TV(P, Q) = TV(Q, P)$ |
| **Range** | $0 \leq TV(P, Q) \leq 1$ |
| **Triangle Inequality** | $TV(P, R) \leq TV(P, Q) + TV(Q, R)$ |
| **Metrical** | 满足 metric 的所有公理 |

### Intuition Building
TV distance 可以理解为：如果我们有两个 distributions，**最多有多少概率质量需要移动**才能将一个 distribution 变成另一个。

**几何解释**：在概率 simplex 上，TV distance 是两个概率点之间的 $L_1$ 距离的一半。

### 局限性
- **不够敏感**：对于高维空间中的 distributions，TV distance 可能无法有效捕捉细微差异
- **不可微**：absolute value 函数在零点不可微，影响优化

## 2. Kullback-Leibler Divergence (KL Divergence)

### Definition
**KL divergence**（又称 relative entropy）定义为：

$$D_{KL}(P \| Q) = \sum_{x \in \mathcal{X}} P(x) \log \frac{P(x)}{Q(x)}$$

对于 continuous case：

$$D_{KL}(P \| Q) = \int_{\mathcal{X}} p(x) \log \frac{p(x)}{q(x)} \, dx$$

其中：
- $P$：true distribution（真实分布）
- $Q$：approximating distribution（近似分布）
- $\|$：分隔符，表示 "P 相对于 Q"
- $\log$：通常使用 natural logarithm（底数为 e）

### 展开形式

$$D_{KL}(P \| Q) = \sum_{x} P(x) \log P(x) - \sum_{x} P(x) \log Q(x)$$

$$= -H(P) + H(P, Q)$$

其中：
- $H(P)$：P 的 entropy（熵），$H(P) = -\sum_x P(x) \log P(x)$
- $H(P, Q)$：cross-entropy（交叉熵）

### 关键性质

| 性质 | 描述 |
|------|------|
| **Non-negativity** | $D_{KL}(P \| Q) \geq 0$ |
| **Identity** | $D_{KL}(P \| Q) = 0 \Leftrightarrow P = Q$ (a.e.) |
| **Asymmetry** | $D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ 一般情况下 |
| **Not a metric** | 不满足 symmetry 和 triangle inequality |

### 两种方向的 KL Divergence

**Forward KL**：$D_{KL}(P \| Q)$
- Mode-seeking behavior
- 当 $P(x) > 0$ 但 $Q(x) \to 0$ 时，惩罚巨大
- 用于 maximum likelihood estimation

**Reverse KL**：$D_{KL}(Q \| P)$
- Mass-covering behavior
- 当 $Q(x) > 0$ 但 $P(x) \to 0$ 时，鼓励 $Q(x) \to 0$
- 用于 variational inference

### Intuition Building
KL divergence 衡量的是：**使用 Q 来近似 P 时损失的"信息量"**。

**信息论解释**：
- 如果 P 是真实分布，Q 是模型分布
- KL divergence 表示：**平均每个样本需要多少额外的 bits**来编码，如果使用 Q 的最优编码而非 P 的最优编码

**概率解释**：
$$D_{KL}(P \| Q) = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right]$$

### 与其他概念的联系

$$D_{KL}(P \| Q) = H(P, Q) - H(P)$$

- Cross-entropy loss = KL divergence + entropy of P
- 当 P 固定时，minimizing cross-entropy 等价于 minimizing KL divergence

## 3. Maximum Mean Discrepancy (MMD)

### Definition
**MMD** 是一种基于 kernel 的非参数距离度量，定义在 Reproducing Kernel Hilbert Space (RKHS) 中：

$$MMD^2(P, Q) = \left\| \mathbb{E}_{x \sim P}[\phi(x)] - \mathbb{E}_{y \sim Q}[\phi(y)] \right\|^2_{\mathcal{H}}$$

其中：
- $\phi(x)$：feature map，将 x 映射到 RKHS $\mathcal{H}$
- $\mathcal{H}$：RKHS，由 kernel $k(\cdot, \cdot)$ 定义
- $\|\cdot\|_{\mathcal{H}}$：RKHS 中的 norm

### Kernel Trick 展开
利用 kernel property $k(x, y) = \langle \phi(x), \phi(y) \rangle_{\mathcal{H}}$：

$$MMD^2(P, Q) = \mathbb{E}_{x,x' \sim P}[k(x,x')] - 2\mathbb{E}_{x \sim P, y \sim Q}[k(x,y)] + \mathbb{E}_{y,y' \sim Q}[k(y,y')]$$

其中：
- $k(x, x')$：kernel function 在两个 P 的样本间
- $k(x, y)$：kernel function 在 P 的样本和 Q 的样本间
- $k(y, y')$：kernel function 在两个 Q 的样本间

### Empirical Estimate
给定 samples $\{x_i\}_{i=1}^m \sim P$ 和 $\{y_j\}_{j=1}^n \sim Q$：

$$\widehat{MMD}^2 = \frac{1}{m(m-1)} \sum_{i \neq i'} k(x_i, x_{i'}) - \frac{2}{mn} \sum_{i,j} k(x_i, y_j) + \frac{1}{n(n-1)} \sum_{j \neq j'} k(y_j, y_{j'})$$

### 常用 Kernel 选择

| Kernel | 公式 | 特点 |
|--------|------|------|
| **Linear** | $k(x, y) = x^T y$ | 简单，计算快 |
| **Polynomial** | $k(x, y) = (x^T y + c)^d$ | 捕捉多项式关系 |
| **RBF/Gaussian** | $k(x, y) = \exp\left(-\frac{\|x-y\|^2}{2\sigma^2}\right)$ | 最常用，universal kernel |
| **Laplacian** | $k(x, y) = \exp\left(-\frac{\|x-y\|_1}{\sigma}\right)$ | 比 RBF 更 robust |

其中：
- $\sigma$：bandwidth parameter（带宽参数）
- $d$：polynomial degree
- $c$：constant term

### 关键性质

| 性质 | 描述 |
|------|------|
| **Metric** | 如果 kernel 是 characteristic 的，MMD 是 valid metric |
| **Differentiable** | 对样本可微，便于优化 |
| **Kernel Freedom** | 可选择不同 kernel 以适应不同数据 |
| **Sample-based** | 可直接从 samples 估计，无需知道 density |

### Characteristic Kernel
一个 kernel $k$ 是 **characteristic** 的，当且仅当：

$$MMD(P, Q) = 0 \Leftrightarrow P = Q$$

Gaussian RBF kernel 是 characteristic kernel。

### Intuition Building
MMD 的核心思想是：**将 distributions 嵌入到高维 RKHS 中，然后计算 mean embedding 之间的距离**。

**为什么有效？**
- 在原始空间中，两个 distributions 的 mean 可能相同
- 但在 high-dimensional (甚至 infinite-dimensional) feature space 中，更多统计量被捕捉
- 如果 kernel 是 characteristic 的，mean embedding 可以唯一确定 distribution

**可视化理解**：
```
Original Space:        RKHS (Feature Space):
   P ~ ○○○○            φ(P) ~ ●●●● (mean embedding)
   Q ~ ××××            φ(Q) ~ ★★★★ (mean embedding)
                          
   Mean(P) ≈ Mean(Q)   ||E[φ(P)] - E[φ(Q)]||² = MMD²
   (可能相同)              (可以区分不同分布)
```

## 4. Wasserstein Distance (Wasserstein-1, Wasserstein-2)

### 背景：Optimal Transport Problem
Wasserstein distance 源自 **optimal transport theory**，核心问题是：**将一个 probability distribution "搬运" 到另一个 distribution 的最小代价是多少？**

### Wasserstein-1 (Earth Mover's Distance)

#### Definition
$$W_1(P, Q) = \inf_{\gamma \in \Pi(P, Q)} \int_{\mathcal{X} \times \mathcal{X}} c(x, y) \, d\gamma(x, y)$$

其中：
- $\inf$：下确界
- $\gamma$：joint distribution（联合分布），称为 transport plan
- $\Pi(P, Q)$：所有 marginal distributions 为 P 和 Q 的 joint distributions 的集合
- $c(x, y) = \|x - y\|$：cost function，通常用 L1 或 L2 norm

#### Kantorovich-Rubinstein Duality
$$W_1(P, Q) = \sup_{\|f\|_L \leq 1} \left| \mathbb{E}_{x \sim P}[f(x)] - \mathbb{E}_{y \sim Q}[f(y)] \right|$$

其中：
- $\|f\|_L$：Lipschitz constant of f
- $\sup$：在所有 1-Lipschitz functions 上取上确界

### Wasserstein-p Distance (General Form)

$$W_p(P, Q) = \left( \inf_{\gamma \in \Pi(P, Q)} \int_{\mathcal{X} \times \mathcal{X}} \|x - y\|^p \, d\gamma(x, y) \right)^{1/p}$$

其中：
- $p \geq 1$：order parameter
- $W_p$：p-th order Wasserstein distance

### Wasserstein-2 Distance

$$W_2(P, Q) = \left( \inf_{\gamma \in \Pi(P, Q)} \mathbb{E}_{(x,y) \sim \gamma}\left[\|x - y\|^2\right] \right)^{1/2}$$

### Discrete Case
对于两个 discrete distributions $P = \sum_{i=1}^n p_i \delta_{x_i}$ 和 $Q = \sum_{j=1}^m q_j \delta_{y_j}$：

$$W_p^p(P, Q) = \min_{T \in \mathbb{R}_+^{n \times m}} \sum_{i,j} T_{ij} \|x_i - y_j\|^p$$

约束条件：
$$\sum_j T_{ij} = p_i, \quad \sum_i T_{ij} = q_j$$

其中：
- $T_{ij}$：从 $x_i$ 运送到 $y_j$ 的 probability mass
- $T$：transport matrix（运输矩阵）

### 关键性质对比

| 性质 | $W_1$ | $W_2$ |
|------|-------|-------|
| **Definition** | $\inf \mathbb{E}[\|x-y\|]$ | $\inf \mathbb{E}[\|x-y\|^2]^{1/2}$ |
| **Metric** | Yes | Yes |
| **对 outlier 敏感度** | 较低 | 较高 |
| **几何结构** | Linear | 平方关系，更强调大距离 |
| **Riemannian Structure** | No | Yes (on probability manifold) |

### Wasserstein Geometry (Optimal Transport Geometry)

对于 $W_2$，在 probability distributions 的空间上存在 **Riemannian structure**：

**Wasserstein geodesic**（测地线）：
$$P_t = ((1-t)Id + tT)\#P_0$$

其中：
- $t \in [0, 1]$：interpolation parameter
- $T$：optimal transport map from $P_0$ to $P_1$
- $\#$：pushforward operation

### Intuition Building

**Earth Mover's Analogy**：
- 想象有两个土堆（distributions）
- Wasserstein distance 是**将一个土堆完全搬运到另一个位置的最小"工作量"**
- "工作量" = 距离 × 移动的土量

**为什么叫 Wasserstein？**
以 mathematician Leonid Vaserstein（英文拼写为 Wasserstein）命名。

**与其他距离的对比**：
```
P = N(0, 1), Q = N(μ, 1)

TV(P, Q): 对于小的 μ，变化缓慢；当 μ 很大时趋于常数
KL(P||Q): ~ μ²/2 (smooth)
MMD(P, Q): ~ |μ| (依赖于 kernel)
W_2(P, Q): = |μ| (exact!)

Wasserstein 对 location shift 非常敏感且线性
```

### Wasserstein GAN (WGAN) Connection

**Standard GAN 问题**：
训练时 discriminator 和 generator 的 loss 可能不连续，导致梯度消失。

**WGAN 解决方案**：
使用 $W_1$ 作为 loss：
$$\min_G \max_{D \in \mathcal{D}} \mathbb{E}_{x \sim P_r}[D(x)] - \mathbb{E}_{z \sim P_z}[D(G(z))]$$

其中：
- $\mathcal{D}$：1-Lipschitz functions 的集合
- $P_r$：real data distribution
- $P_z$：noise distribution

## 5. 综合对比与选择指南

### Theoretical Properties Comparison

| Property | TV | KL | MMD | Wasserstein |
|----------|----|----|-----|-------------|
| **Symmetric** | ✅ | ❌ | ✅ | ✅ |
| **Triangle Inequality** | ✅ | ❌ | ✅ | ✅ |
| **True Metric** | ✅ | ❌ | ✅ (char. kernel) | ✅ |
| **Differentiable** | ❌ | ✅ | ✅ | ✅ (dual form) |
| **Sample-based** | ✅ | ✅ | ✅ | ✅ |
| **Handles non-overlapping support** | ✅ | ❌ (inf) | ✅ | ✅ |

### Behavior on Different Distributions

考虑 $P = \delta_0$ (point mass at 0) 和 $Q_\epsilon = \delta_\epsilon$ (point mass at ε)：

| Distance | Value | Limit as ε → 0 |
|----------|-------|----------------|
| $TV(P, Q_\epsilon)$ | 1 | 1 (不连续!) |
| $D_{KL}(P \| Q_\epsilon)$ | $\infty$ | $\infty$ |
| $MMD(P, Q_\epsilon)$ | $O(\sqrt{k(0) - k(\epsilon)})$ | 0 (连续) |
| $W_p(P, Q_\epsilon)$ | $\epsilon$ | 0 (线性连续) |

### Topological Considerations

| Distance | Topology | Implication |
|----------|----------|-------------|
| TV | Total variation norm topology | Strong topology |
| KL | Not a metric | Weak convergence under certain conditions |
| MMD | Weak topology (induced by kernel) | Depends on kernel choice |
| Wasserstein | Weak topology + moments | Natural for probability measures |

### 选择指南

| 场景 | 推荐方法 | 原因 |
|------|----------|------|
| **GAN training** | Wasserstein-1 | 稳定，梯度有意义 |
| **Variational Inference** | Reverse KL | Computationally tractable |
| **Two-sample test** | MMD | Non-parametric，powerful |
| **Distribution with non-overlapping support** | Wasserstein | 有限值，有意义 |
| **Information theory** | KL | Natural interpretation |
| **Robust statistics** | TV or W_1 | Less sensitive to outliers |

## 6. 数学关系与不等式

### Pinsker's Inequality
$$TV(P, Q) \leq \sqrt{\frac{1}{2} D_{KL}(P \| Q)}$$

这建立了 KL divergence 和 TV distance 的关系。

### Wasserstein vs KL
对于 distributions on bounded domain $\Omega$ with diameter $D$：

$$W_1(P, Q) \leq D \cdot \sqrt{D_{KL}(P \| Q)}$$

### TV vs Wasserstein
$$W_1(P, Q) \leq \text{diam}(\Omega) \cdot TV(P, Q)$$

### MMD and Integral Probability Metrics (IPM)
MMD 是 IPM 的特例：
$$IPM_{\mathcal{F}}(P, Q) = \sup_{f \in \mathcal{F}} \left| \mathbb{E}_P[f] - \mathbb{E}_Q[f] \right|$$

- TV: $\mathcal{F} = \{f: \|f\|_\infty \leq 1\}$
- $W_1$: $\mathcal{F} = \{f: \|f\|_L \leq 1\}$ (1-Lipschitz)
- MMD: $\mathcal{F} = \{f: \|f\|_{\mathcal{H}} \leq 1\}$ (unit ball in RKHS)

## 7. 计算复杂度与实现

### Computational Complexity

| Method | Exact | Approximation |
|--------|-------|---------------|
| TV | $O(n)$ for discrete | - |
| KL | $O(n)$ for discrete | - |
| MMD | $O(n^2)$ naive, $O(n)$ linear-time estimate | Random Fourier Features |
| $W_1$ | $O(n^3)$ (linear programming) | Sinkhorn: $O(n^2 k)$ |
| $W_2$ | $O(n^3)$ | Sinkhorn, Sliced Wasserstein |

其中：
- $n$：number of samples
- $k$：number of Sinkhorn iterations

### Sinkhorn Algorithm for Wasserstein
Entropic regularization：
$$W_p^p(P, Q) \approx \inf_{\gamma} \int c(x,y) d\gamma - \epsilon H(\gamma)$$

其中：
- $\epsilon$：regularization parameter
- $H(\gamma) = -\int \gamma \log \gamma$：entropy

**Algorithm**：
$$K_{ij} = \exp(-c(x_i, y_j)/\epsilon)$$

Iterate:
$$u \leftarrow \frac{p}{Kv}, \quad v \leftarrow \frac{q}{K^T u}$$

直至收敛，transport matrix：$T = \text{diag}(u) K \text{diag}(v)$

## 8. 高级主题与扩展

### Sliced Wasserstein Distance
将高维问题投影到一维：

$$SW_p(P, Q) = \left( \int_{S^{d-1}} W_p^p(P_{\theta}, Q_{\theta}) d\theta \right)^{1/p}$$

其中：
- $S^{d-1}$：d-维单位球面
- $P_\theta, Q_\theta$：沿方向 $\theta$ 的投影分布
- 优点：计算效率高，$O(n \log n)$

### Energy Distance
MMD 的特例（使用 distance kernel）：

$$E(P, Q) = 2\mathbb{E}\|X-Y\| - \mathbb{E}\|X-X'\| - \mathbb{E}\|Y-Y'\|$$

与 $W_1$ 相关：
$$E(P, Q) \geq c \cdot W_1(P, Q)$$

### f-Divergence Family
KL divergence 的推广：

$$D_f(P \| Q) = \int q(x) f\left(\frac{p(x)}{q(x)}\right) dx$$

| f(x) | Divergence |
|------|------------|
| $x \log x$ | KL |
| $\frac{1}{2}|x-1|$ | TV |
| $x \log x - (x-1)$ | Reverse KL |
| $(\sqrt{x}-1)^2$ | Hellinger² |
| $-\log x + x - 1$ | Jeffrey's |
