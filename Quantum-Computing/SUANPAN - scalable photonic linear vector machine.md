## 🎯 研究背景与动机

### 当前光学计算的瓶颈

传统光子计算架构（如Stanford结构、Reck方案、深度衍射架构等）都基于**光束相互作用**（相干或非相干叠加）来执行向量-矩阵乘法：

| 传统架构 | 基本单元 | 相互作用方式 | 可扩展性限制 |
|---------|---------|-------------|------------|
| Stanford结构 | 分束器/组合器 | 相干/非相干叠加 | 强耦合限制扩展 |
| Reck方案 | MZI阵列 | 相干干涉 | MZI数量随维度²增长 |
| 深度衍射架构 | 衍射层 | 衍射/散射 | 层间耦合复杂 |
| 微环谐振器阵列 | MRR | 共振耦合 | 热串扰问题 |

**核心问题**: 这些架构的基本单元之间**强耦合**或**高度互联**，无法通过简单复制基本单元来提高维度。

### SUANPAN的突破思路

SUANPAN跳出了"通过光束相互作用实现光学矩阵变换"的传统思维，采用**无相互作用**的独立发射器-探测器对设计。

## 🏗️ SUANPAN架构详解

### 基本结构

SUANPAN由三个主要部分组成：

```
┌─────────────────────────────────────────────────┐
│           SUANPAN Architecture                   │
├─────────────────────────────────────────────────┤
│                                                 │
│   ┌─────────────┐              ┌────────────┐   │
│   │  VCSEL      │───────光─────▶│  MoTe2 PD  │   │
│   │  Array      │  (无相互作用) │  Array     │   │
│   │  (8×8)      │              │  (8×8)     │   │
│   └──────┬──────┘              └─────┬──────┘   │
│          │                            │         │
│          │                            │         │
│     数字编码控制                    模拟电流总和  │
│          │                            │         │
│          └────────┬───────────────────┘         │
│                   ▼                              │
│            单个ADC读取                           │
│                   ▼                              │
│           数字输出结果                            │
└─────────────────────────────────────────────────┘
```

![[Pasted image 20260128195200.png]]
### 关键概念：BEAD（Basic Emitter-Detector）

每个BEAD = 一个发射器-探测器对，命名为 **Bit Encoding and Analog Detecting**。

#### 数学原理

对于两个元素 a 和 b 的乘法：

**步骤1: 乘法运算**
```
I_light = f(a)  (光强度编码a)
I_dark  = 0     (关断时的光强)
R_PD    = g(b)  (光探测器响应度编码b)

光电流 I_photo = I_light × R_PD ∝ a × b
```

**步骤2: 累加运算**
```
总电流 I_total = Σ I_photo_i  (基尔霍夫定律)
```

### 向量内积的计算流程

对于两个向量 A = [a₁, a₂, ..., a_N] 和 B = [b₁, b₂, ..., b_N] 的内积：

$$A \cdot B = \sum_{i=1}^{N} a_i \times b_i$$

**SUANPAN实现流程**:

1. **编码阶段**:
   - 向量A的每个元素 aᵢ 编码为第i个VCSEL的光强度（时间域编码）
   - 向量B的每个元素 bᵢ 编码为第i个MoTe2 PD的光响应度（空间域编码）

2. **计算阶段**:
   - 每个BEAD独立计算 aᵢ × bᵢ
   - 所有PD的输出电流自然累加

3. **读取阶段**:
   - 单个ADC读取总电流
   - 得到内积结果

## ⚙️ 位编码与模拟检测（BEAD）原理

### 时间-空间编码方案

SUANPAN的核心创新在于**时间域编码乘数a**和**空间域编码乘数b**。

### 编码方法详解
![[Pasted image 20260128195218.png]]
#### 1-bit 量化（图2a)

```
a 编码: 通过占空比控制（时间域）
  |█████████|           (duty cycle = a/T, a ∈ [0,1])
  
b 编码: BEAD的开关状态（空间域）
  b = 0 → BEAD 关断 → I_photo = 0
  b = 1 → BEAD 开启 → I_photo ∝ a

总光电流: I_total = a × b
```

#### 2-bit 量化（图2b)

需要2个BEAD组成一组，对应b的2位二进制表示：

```
b的二进制: b = b₁b₀ (b₁为高位, b₀为低位)

BEAD₀ (低位, 权重2⁰): 
  响应度 R₀ = R_base (基准响应度)
  
BEAD₁ (高位, 权重2¹): 
  响应度 R₁ = 2 × R_base

编码示例:
  b = 0  = 00 → BEAD₀:关, BEAD₁:关 → I_total = 0
  b = 1  = 01 → BEAD₀:开, BEAD₁:关 → I_total = a×R₀
  b = 2  = 10 → BEAD₀:关, BEAD₁:开 → I_total = a×2R₀
  b = 3  = 11 → BEAD₀:开, BEAD₁:开 → I_total = a×3R₀
```

#### M-bit 量化（图2c)

使用M个BEAD组成一组，第k个BEAD的权重为2ᵏ：

```
b的值: b = Σ(b_k × 2^k), k = 0, 1, ..., M-1

第k个BEAD的响应度: R_k = 2^k × R_base

总光电流: I_total = Σ(I_k × b_k) 
                    = Σ(a × R_k × b_k)
                    = a × R_base × Σ(2^k × b_k)
                    = a × b × R_base
```

### 时间-空间编码示例（图2d）

假设 a ∈ [0, 100]（通过0-100%占空比编码），b为4-bit量化（使用4个BEAD）：

```
时间周期 T = 100 时钟周期

a = 50 → 50个周期开, 50个周期关 → 占空比 50%
b = 5  = 0101 (二进制)
      → BEAD₀(权重1): 开
      → BEAD₁(权重2): 关
      → BEAD₂(权重4): 开
      → BEAD₃(权重8): 关

总光电流 ∝ a × (1×1 + 2×0 + 4×1 + 8×0) = a × 5
```

### 向量内积实现（图2e)

对于N维向量，需要N组BEAD，每组包含M个BEAD（M-bit精度）：

```
总BEAD数 = N × M

向量A = [a₁, a₂, ..., a_N]
向量B = [b₁, b₂, ..., b_N], 每个bᵢ为M-bit

第i组BEAD实现 aᵢ × bᵢ:
  I_i = a_i × R_base × Σ(2^k × b_ik)

最终内积:
  A·B = R_base⁻¹ × Σ(I_i)
      = Σ(a_i × b_i)
```

### 负数处理

对于有符号数，需要2×M个BEAD（M个正，M个负）：

```
正数部分: 使用M个BEAD, 正偏置电压
负数部分: 使用M个BEAD, 反向偏置电压

最终内积 = I_positive - I_negative
```

### 2. AI应用1: Ising Problem Solver

#### Ising问题定义

Ising问题是NP困难的组合优化问题，哈密顿量为：

$$H = S^T J S = \sum_{i,j} J_{ij} S_i S_j$$

其中:
- S = [S₁, S₂, ..., S_N], S_i ∈ {+1, -1}
- J: N×N对称耦合矩阵, J_ii = 0
- 目标: 找到使H最小的S（基态）

#### 模拟退火（SA）算法

每步迭代中需要计算哈密顿量变化 ΔH：

$$\Delta H = 2 S_k \sum_{i} J_{ik} S_i$$

这是一个**N维向量内积**，可由SUANPAN加速。

## 🚀 计算性能分析

### 当前实现性能

#### 延迟分解

```
单BEAD延迟 t_B = t_e + t_p + t_d
              = 编码时间 + 传播时间 + 检测时间

具体数据:
  t_e (VCSEL编码) = 1 μs (100 MHz, 100周期)
  t_p (光传播)    = 5 ns   (1.5m距离)
  t_d (PD检测)    = 6.59 μs (响应速度瓶颈)
  
  t_B = 1 μs + 5 ns + 6.59 μs ≈ 7.59 μs
```

#### 吞吐量计算

```
单BEAD速度:
  Speed_B = 1 / t_B = 1 / (7.59 × 10⁻⁶ s) 
          ≈ 132 KOPS (千次操作/秒)

SUANPAN整体速度:
  - BEAD总数: 64
  - 8-bit量化 (使用8个BEAD计算一个乘法)
  - 有效并行度: 64 / 8 = 8
  
  Speed_Total = 132 KOPS × 8 ≈ 1.05 MOPS
```

### 未来预测性能

通过工艺改进和架构优化，理论性能可达：

#### 改进措施

| 改进项 | 当前值 | 目标值 | 性能提升 |
|--------|--------|--------|---------|
| 发射器-探测器距离 | 1.5 m | <1 mm | t_p: 5 ns → 3.3 ps |
| BEAD尺寸 | N/A | <10 μm | 密度提升 |
| 操作带宽 | 100 MHz | >1 GHz | 速度提升10倍 |
| VCSEL集成 | 分离 | 同芯片 | 功耗降低 |
| PD带宽 | ~150 kHz | >50 GHz | 速度提升 |

#### 理论性能计算

```
单延迟 (改进后):
  t'_B ≈ t_d' (PD响应, 主导)
      ≈ 1 / (50 GHz) = 20 ps

单BEAD速度:
  Speed'_B = 1 / t'_B ≈ 50 GOPS

芯片密度 (BEAD尺寸<10 μm):
  密度 = 1 / (10 μm)² = 10⁸ BEADs/cm² = 100 MBEADs/cm²

1-bit计算性能:
  POPS_1bit = 50 GOPS × 100 MBEADs/cm² 
            = 5 × 10¹⁸ OPS/cm² 
            ≈ 5 EOPS/cm² (艾 ops/cm²)

注意: 如论文所述为>1 POPS/cm²，可能是保守估计
```

### 能耗分析

```
单BEAD能耗:
  P_VCSEL ≈ 2.5 mW  (主导项)
  P_PD    ≈ 273.4 nW
  P_total = 2.5 mW + 0.0003 mW ≈ 2.5 mW

能耗密度 (8-bit, 8 BEADs/运算):
  E/op = 8 BEADs × 2.5 mW × t_B
       = 20 mW × 7.59 μs
       = 151.8 μJ/op

问题: 
  • VCSEL光束扩散，PD有效接收面积小
  • 光斑半径~200 μm，PD通道仅10 μm
  • 大部分光功率未被利用
  
改进方向:
  • 同芯片集成 → 光耦效率显著提升
  • 预计能耗可降低100-1000倍
```

## 💡 SUANPAN架构的核心优势

### 1. 可扩展性

**传统架构限制**:
```
光学矩阵变换架构:
  • 单元间强耦合
  • 增加维度 → 重新设计整个系统
  • 累积误差和串扰问题
```

**SUANPAN优势**:
```
独立BEAD设计:
  • BEAD间无光束相互作用
  • 增加维度 → 简单增加BEAD数量
  • 无额外损耗或误差累积
  • 理论上无限可扩展
```

### 2. 可重构性和可编程性

```
可重构:
  • 根据位精度调整每组BEAD数量
  • M-bit精度 → M BEADs/组

可编程:
  • 灵活编码每个BEAD的开关状态
  • 动态调整计算任务

应用:
  • Ising solver → 矩阵-向量乘
  • ANN          → 矩阵-矩阵乘(按列)
  • 优化问题     → 不同编码方式
```

### 3. 硬件简化

```
传统光子计算:
  • 每个光源需要1个DAC → N个DAC
  • 每个探测器需要1个ADC → N个ADC
  • 总计: 2N个精密DAC/ADC

SUANPAN (BEAD paradigm):
  • 每个BEAD只需1位控制 → 简单数字电路
  • 所有PD电流自然叠加 → 仅需1个ADC
  • 总计: 0个DAC + 1个ADC

硬件优势:
  • 面积和功耗降低
  • 成本降低
  • 优势在高应用中更明显
```

### 4. 抗失效能力

```
传统架构:
  • 单元间耦合 → 单点故障影响整体
  • 维修成本高

SUANPAN:
  • BEAD完全独立
  • 单个BEAD失效 → 仅降低维度，不影响其他
  • 容错性好，适合大规模集成
```

### 5. 相位控制简化

```
相干系统:
  • 需要精确相位控制
  • 环境敏感性高
  • 动态调谐复杂

SUANPAN:
  • 单纯强度检测
  • 无需相位校正
  • 环境鲁棒性强
```

## 🔧 技术挑战与未来方向

### 当前局限

1. **速度瓶颈**: 当前PD响应速度(μs级)远低于VCSEL(ns级)
2. **光耦合效率**: 空间分离导致效率低
3. **器件稳定性**: 2D材料长期性能退化问题
4. **精度限制**: 虽然可扩展到高位，但当前演示主要为4-8 bit

### 改进方向

#### 1. 器件集成

```
目标: VCSEL + PD 同芯片集成

方法:
  • 3D垂直集成
  • 波导耦合
  • 异构集成技术

预期收益:
  • 传播时间 → ns → ps
  • 耦合效率 → 10% → >80%
  • 功耗 → 降低10-100倍
```

#### 2. 高带宽探测器

参考文献[32]: Metamaterial graphene photodetector with bandwidth exceeding 500 GHz

```
Graphene基PD的优势:
  • 超高载流子迁移率
  • 宽波长响应
  • 超高速响应
```

### 关键公式总结

**1. 向量内积**:
$$A \cdot B = \sum_{i=1}^{N} a_i \times b_i$$

**2. Ising哈密顿量**:
$$H = S^T J S$$

**3. SUANPAN光电流**:
$$I_{total} = \sum_{k=1}^{N} \sum_{m=0}^{M-1} a_k \times R_m \times b_{km}$$

其中:
- aₖ: 向量A的第k个元素（光强度编码）
